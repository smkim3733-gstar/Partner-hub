# ChatGPT 자가등록 중복 이메일 무결성

기준일: 2026-09-05

## 확인한 문제

기존 관리 화면은 신규 중복 이메일 저장을 차단하지만, 과거 자료 이관·손상 상태처럼 같은 정규화 이메일의 회원이 이미 둘 이상 존재할 수 있다. ChatGPT 자가등록은 첫 일치 회원만 선택했기 때문에 첫 회원이 승인대기이고 뒤 회원이 활성인 경우 활성 계정 존재를 놓치고 첫 회원을 갱신하거나 안정 사용자 ID를 결속할 수 있었다. 수정 전 실제 라우트 재현에서는 이 요청이 HTTP 200을 반환했다.

## 적용한 경계

- 자가등록은 신청 이메일과 일치하는 기존 회원 전체를 먼저 계산한다.
- 일치 회원이 둘 이상이면 회원 상태·비밀번호 자격·안정 ID 결속을 처리하기 전에 HTTP 409로 거절한다.
- 거절된 요청은 회원 명단, `membersRevision`, 비밀번호 자격과 `portal_chatgpt_identity_bindings`를 변경하지 않는다.
- 일치 회원이 없거나 정확히 1명인 정상 신규등록·안전 재시도·활성·정지 계정 처리 의미는 유지한다.
- 이미 적용된 포털 접속 중복 이메일 차단, 안정 ID 단방향 해시, D1 고유 제약과 동일 출처·속도 제한 경계는 유지한다.

## 검증

- 수정 전: 첫 승인대기·뒤 활성 회원이 같은 이메일인 상태에서 자가등록이 HTTP 200을 반환했다.
- 수정 후: 같은 요청은 HTTP 409이며 회원 상태와 결속 행은 그대로다.
- Node 회귀 테스트 487/487 통과.
- 격리 workerd+D1+R2 검사 181/181 통과. 운영 쓰기·이메일·유료 AI·외부 요청은 모두 0건이다.
- 타입검사, 전체 lint, 프로덕션 빌드 통과.
- 로컬 운영 Worker의 `/`, `/account`, `/account/setup` 모두 HTTP 200.

## 저장 상태

기능 커밋 `8a7fb7754354ccb8da374ad5eb722b6782cfa931`을 GitHub `main`과 Sites 소스 저장소에 반영했다. 같은 커밋의 검증된 빌드 산출물을 Sites 버전 120 (`appgprj_6a92514801988191b79eb9bd314e3fcd~appgver_0369667769b4819187b41d5bf4c4ac15`)으로 저장했다.

현재 공개 운영본은 버전 107이다. 버전 108~119는 버전 120으로 대체하며 공개 배포하지 않는다. 버전 120도 정확한 운영 배포 승인 전까지 저장 상태로 유지한다. D1 스키마, R2 연결, 공개 범위, 데이터 보관·삭제 정책은 변경하지 않았다.

# 운영 업무 사이트 알림

2026-09-03. 사용자의 연속 개발 요청으로 상단 알림 숫자의 가상 예시 오집계와 모바일 메뉴의 알림 건수 누락을 보완했다.

## 변경

- 서버가 현재 계정에 반환한 업무 중 오늘 마감·기한 지연이며 완료되지 않은 운영 업무만 알림 숫자로 센다.
- 예약된 가상 예시 업무 ID는 제목이나 상태와 무관하게 알림 숫자에서 제외한다. 운영 알림이 없는 가상 기준선은 `0건`으로 유지한다.
- 데스크톱 상단 알림 버튼과 주요 메뉴·모바일 메뉴의 `업무·알림` 항목에 같은 운영 알림 숫자를 전달한다.
- 업무 화면 안내를 실제 동작에 맞춰 수정했다. 외부 푸시·이메일·문자 발송, 읽음 상태, 새 DB 기록은 추가하지 않았다.

## 검증 경계

- 자동 테스트 254개, 타입검사, lint, 프로덕션 빌드 통과.
- 가상 예시·완료·향후 업무 제외, 오늘·기한 지연 운영 업무 포함, 호출자가 넘긴 서버 권한 후보만 집계, 알림 없는 메뉴 문구를 회귀검증한다.
- 격리 workerd/D1/R2 검사 129개 통과. 실제 쓰기·메일·유료 AI·외부 요청은 0건이다.
- localhost `/` 응답은 HTTP 200이다.
- 서버 API, DB/R2 스키마, 권한·보관 정책은 변경하지 않았다. GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다. 반영 뒤 결과는 `outputs/release/portal-task-notifications-deployment.json`을 기준으로 한다.

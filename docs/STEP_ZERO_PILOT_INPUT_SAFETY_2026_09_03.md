# Step 0 가상시험 입력 안전성

2026-09-03 기준 유료 외부 AI 호출 전 가상기업 입력과 현재 동의를 화면·서버가 같은 규칙으로 확인하도록 정리했다.

## 변경 내용

- 새 화면과 다른 가상기업 선택 뒤 입력란은 빈 상태로 시작한다. 특정 제조업·업력·요청사항을 자동 입력하지 않는다.
- 가상기업 설명은 공백을 정리하고 20자 이상 8,000자 이하인지 화면과 서버에서 함께 검증한다.
- 8,000자를 넘긴 요청은 일부만 잘라 외부 AI로 보내지 않고 전체 요청을 거절한다.
- 전화번호·이메일·사업자번호·주민번호 형태가 포함되면 외부 호출 전에 차단한다.
- 입력 내용을 바꾸면 기존 체크를 해제해 변경된 전체 내용을 다시 확인하고 동의해야 한다.
- 생성 성공 뒤에도 동의를 해제해 같은 입력의 다음 유료 실행을 별도로 확인한다.
- 입력·동의 오류는 해당 입력으로 초점을 이동하고 외부 호출을 시작하지 않는다.

## 유지한 경계

- Step 0 생성은 기존처럼 대표 관리자, A 판정 가상기업, 저장 원본·마스킹·제3자 AI·녹취 동의 사전점검을 모두 통과해야 한다.
- API 키·모델·R2 준비상태, 요청번호 기반 중복·응답 유실 처리와 생성 후 최종 권한·동의·원본 재검증은 유지한다.
- 실제 고객 원본, 실제 계정, 유료 AI를 검증에 사용하지 않았다.
- D1/R2 스키마, 인증·권한, 저장 결과, 보관·삭제 정책은 변경하지 않았다.

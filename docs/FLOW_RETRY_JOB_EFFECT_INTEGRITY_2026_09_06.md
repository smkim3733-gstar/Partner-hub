# 상담 FLOW 작업 재시도 효과 무결성

기준일: 2026-09-06

## 보완 내용

`retry_job` 명령에 허용된 작업 목록 변경을 요청한 기존 작업 한 건의 정확한 재대기 효과에 결속했다.

- `blocked`, `failed`, `processing` 상태의 대상 작업 한 건만 `queued`로 전환할 수 있다.
- 대상 작업의 사유를 비우고 처리 시작시각을 제거한다.
- 현재 실패 증거가 있으면 기존 실패 증거 이력 뒤에 정확히 한 번 보존한 후 현재 증거를 제거한다.
- 다른 작업의 상태·사유·시각·성공/실패 증거는 그대로 보존한다.
- 작업 추가·삭제·재정렬과 여러 작업의 동시 재시도를 거절한다.
- 애플리케이션 커밋 검사와 추가형 `0073` D1 트리거가 같은 예상 작업 배열을 강제한다.

# 파트너 유형 명시 선택 안전성

2026-09-03 기준. 대표의 파트너 직접등록과 승인대기 계정 검토에서 유형이 자동 선택되지 않도록 보완한 기록이다.

## 확인한 문제

- 관리자 직접등록 폼은 새 계정을 `한기평 컨설턴트`로 미리 선택했다.
- 승인대기 카드에는 `유형 선택 필요`라고 표시했지만 검토창도 같은 유형을 자동 선택했다.
- 대표가 유형 선택을 확인하지 않고 등록·승인하면 의도하지 않은 파트너 분류가 저장될 수 있었다.

## 적용한 동작

- 관리자 직접등록 폼은 파트너 유형이 빈 상태로 시작하며 허용된 네 유형 중 하나를 직접 골라야 한다.
- 등록 성공 뒤 초기화할 때도 유형을 빈 상태로 되돌린다.
- 승인대기·초대대기 계정 검토창은 과거 또는 임시 유형 값을 자동 상속하지 않고 매번 빈 상태로 연다.
- 유형 없이 승인하면 저장하지 않고 오류를 표시한 뒤 유형 선택으로 초점을 옮긴다.
- 활성·정지 계정의 설정창은 기존 유형을 유지해 일반 편집 흐름을 바꾸지 않는다.
- 직접등록의 기존 서버 검증과 검토창이 같은 허용 목록을 사용한다.

## 운영 경계

- 기존 활성·정지 계정의 유형, 상태, 권한을 일괄 변경하지 않는다.
- 승인대기 계정을 자동 승인하거나 실제 계정을 새로 만들지 않는다.
- 파트너 유형의 권한 의미, 기본 권한, 로그인·비밀번호 경로, 서버 API, DB/R2 스키마와 보관 정책은 변경하지 않았다.
- 실제 운영 데이터 쓰기, 메일 발송, 유료 AI 호출, 외부 요청은 검증 중 모두 0건이다.

- 빈 값·임의 값 차단과 허용된 네 유형 통과 검사 보강.
- 승인대기·초대대기는 유형을 상속하지 않고 활성·정지 계정만 기존 유형을 유지하는 검사 보강.

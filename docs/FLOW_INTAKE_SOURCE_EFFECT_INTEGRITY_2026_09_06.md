# 상담 FLOW 신청자료 불러오기 효과 무결성

기준일: 2026-09-06

## 보완 내용

`import_intake_source` 명령의 파일 변경을 기존 파일 보존과 새 신청자료 검토본 정확히 한 건에 제한했다.

- 기존 파일의 값과 순서를 모두 보존한다.
- 새 검토본 한 건만 추가하고 용도를 `source`, 생성시각을 FLOW 갱신시각으로 고정한다.
- 새 검토본에 비어 있지 않은 신청 원본 ID와 검토자를 요구한다.
- 신청 원본 내용 증거를 64자 소문자 SHA-256으로 결속하고 검토시각을 FLOW 갱신시각으로 고정한다.
- 검토본 누락·여분 파일·기존 파일 변경·삭제·재정렬을 신청자료 불러오기와 함께 수행하는 것을 거절한다.
- 애플리케이션 커밋 검사와 추가형 `0077` D1 트리거가 같은 효과를 독립 강제한다.

## 검증·저장

- 신청자료 불러오기 명령에서 새 검토본을 제거하고 기존 근거파일만 보관 제외하면 앱과 D1이 모두 거절한다.
- 정상 경로는 원본 ID·SHA-256·검토시각·검토자를 갖춘 새 검토본 한 건과 R2/D1 파일 증거를 함께 저장한다.

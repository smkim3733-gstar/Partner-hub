# 상담 FLOW 전사문 작업 효과 무결성

기준일: 2026-09-06

## 보완 내용

`save_transcript` 명령에 허용된 작업 목록 변경을 선택한 최신 녹취의 4차 작업 한 건에 정확히 결속했다.

- 최신 녹취를 참조하는 마지막 4차 작업만 전사문 보완 효과를 받을 수 있다.
- AI 자동생성이 허용된 경우 대상 작업만 `queued`로 전환하고 사유·시작시각·현재 실패 증거를 정리한다.
- 현재 실패 증거가 있으면 기존 이력 뒤에 정확히 한 번 보존한 후 현재 증거를 제거한다.
- AI 자동생성이 중지된 경우 대상 작업을 고정 사유의 `blocked`로 두며, 중지 상태의 `failed` 작업은 그대로 보존한다.
- 다른 작업의 상태·사유·시각·성공/실패 증거와 작업 추가·삭제·재정렬을 거절한다.
- 애플리케이션 커밋 검사와 추가형 `0072` D1 트리거가 같은 예상 작업 배열을 강제한다.

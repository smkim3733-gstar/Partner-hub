# 상담 FLOW 명령 영수증 신원 정규형 무결성

기준일: 2026-09-06

## 문제·적용

영수증의 요청 지문과 행위자 키는 문자열 길이만 맞으면 저장할 수 있어, 직접 저장 경로에서 SHA-256이 아닌 값이나 정의되지 않은 행위자 키 형식을 새 명령 근거로 넣을 수 있었다. 이제 애플리케이션과 추가형 `0054` D1 트리거가 새 명령 영수증의 지문을 64자 소문자 16진수 SHA-256 정규형으로, 행위자 키를 공백 없는 `admin:` 또는 `member:` 네임스페이스로 제한한다.

## 감사·보존 경계

- 새 명령 요청 지문은 정확히 64자 소문자 16진수여야 한다.
- 새 행위자 키는 `admin:` 또는 `member:` 접두부와 비어 있지 않은 식별값을 가져야 한다.
- 행위자 키에는 ASCII 공백·탭·줄바꿈을 허용하지 않는다.
- 신규 FLOW 행에 명령이 있으면 최초 저장부터 같은 정규형을 적용한다.
- 기존 레거시 영수증은 읽기 호환하며 사후 보충하거나 정규형으로 위장해 다시 쓰지 않는다.
- 실제 브라우저 요청의 지문은 정규화된 명령 JSON과 첨부 메타데이터·실제 바이트 해시에서 계산한다.

# ChatGPT 등록 비밀번호 자격 소유자 결속 무결성

기준일: 2026-09-05

## 해결한 문제

ChatGPT 자가등록은 로그인 이메일과 신청 이메일을 확인하지만, 같은 이메일이 `portal_password_accounts`에서 어느 회원 ID에 결속돼 있는지는 확인하지 않았다. 과거 삭제 회원의 분리된 자격이 남은 이메일로 새 ChatGPT 회원을 만들면 ChatGPT 승인 경로는 진행되지만 이후 비밀번호 설정은 이메일 고유 제약과 충돌할 수 있었다.

## 적용 경계

- ChatGPT 자가등록은 회원을 새로 만들기 전에 대상 이메일의 비밀번호 자격 소유자 ID를 확인한다.
- 명단에 같은 이메일 회원이 없는데 자격이 남아 있으면 HTTP 409로 거절한다.
- 승인대기 회원과 다른 회원 ID의 자격이 같은 이메일을 사용해도 거절한다.
- 승인대기 회원 본인의 ID에 결속된 자격은 허용한다. 동일 신청 재시도는 명단과 revision을 다시 쓰지 않는다.
- 활성 회원과 정지 회원의 기존 안내·상태 보존을 먼저 적용한다.
- 동시 비밀번호 자가가입이 먼저 끝나면 포털 상태 CAS 재시도에서 새 회원 ID와 자격 소유자 ID를 다시 확인한다.

## 의도적으로 하지 않은 일

- 분리된 기존 자격을 자동 삭제·이전·재사용하지 않는다.
- 응답에서 과거 자격의 회원 ID·이메일 외 식별정보·비밀번호 해시를 노출하지 않는다.
- 운영 D1/R2, 실제 회원, 실제 고객자료를 읽거나 변경하지 않는다.
- ChatGPT 인증 방식, 비밀번호 해시, 쿠키, 권한, DB 스키마, 보관·삭제 정책을 변경하지 않는다.

## 검증

- Node 회귀 테스트 478개 통과
- 격리 workerd/D1/R2 검사 163개 통과, 외부 요청·운영 쓰기 0건
- 분리 자격 이메일의 신규 ChatGPT 회원 생성 차단과 명단 무변경 확인
- 승인대기 회원과 동일 ID에 결속된 정상 자격의 무기록 재시도 확인
- 기존 대표 직접등록·이메일 변경 예약 차단과 비밀번호 생명주기 검사 유지 확인

## 릴리스 상태

검증된 기능 커밋과 Sites 저장 버전은 패키징 완료 뒤 기록한다. 현재 공개 운영본 버전 107은 이번 저장 단계에서 변경하지 않는다.

# 지원 요청 유형·처리시간 지표

## 목적

파트너 허브 안에서 실제 지원 요청을 등록하고, 대표가 요청을 인지한 시각과 처리를 완료한 시각을 서버 기록으로 구분한다. 대표 대시보드에는 고정 유형별 합계와 충분한 표본이 있는 거친 시간 구간만 제공한다.

## 지원 요청 모델

- 기존 업무·알림 레코드에 `지원요청` 유형을 추가한다. 별도 지원 본문·첨부·고객자료 저장소는 만들지 않고 기존 업무 제목을 요청 설명으로 사용한다.
- 지원 범위 회사값은 `파트너 허브 지원`으로 고정해 계정·저장 문제에 무관한 고객사명이 남지 않게 한다.
- 지원 유형은 로그인·계정, 저장·동기화, 파일·자료, 상담 FLOW, 기타의 다섯 가지 고정 분류만 사용한다.
- 지원 요청은 요청자에게 계속 배정한다. 대표가 처리하더라도 요청자 화면에서 사라지도록 담당을 이전하지 않는다.
- 신규 요청은 서버가 대기 상태, 등록시각, 등록 주체 역할, 현재 처리 주기 1을 기록한다. 클라이언트가 보낸 시각·처리자·주기·등록 주체 값은 사용하지 않는다.
- 대표가 처음 대기에서 진행으로 바꾸면 인지시각을 기록한다. 대표가 대기 상태에서 바로 완료하면 인지와 완료를 같은 서버 시각으로 기록한다.
- 대표 완료와 요청자 자가종료는 서버가 현재 로그인 역할로 구분한다. 요청자 자가종료는 대표 처리시간에 포함하지 않는다.
- 완료된 요청을 다시 열면 새로운 최신 처리 주기를 시작한다. 요청자가 다시 열면 대기로, 대표가 다시 진행하면 즉시 인지된 진행 상태로 기록한다.

## 집계 정의

- 가상 예시가 아닌 현재 업무만 집계한다.
- 유형 합계와 등록 주체 합계는 각각의 주변합만 제공하고 서로 교차한 작은 칸은 만들지 않는다.
- 대표 인지 대기, 대표 처리 중, 대표 완료, 요청자 자가종료, 재개된 현재 주기, 기존 측정 불가, 시각·상태 이상을 분리한다.
- 대표 인지시간은 서버 등록시각부터 대표 인지시각까지다. 대표 처리시간은 서버 등록시각부터 대표 완료시각까지며 요청자 자가종료를 제외한다.
- 미인지 대기 연령은 아직 대표 인지시각이 없는 열린 요청의 서버 등록시각부터 현재 요청 시각까지다.
- 대표 인지시간, 대표 처리시간, 미인지 대기 연령은 각각 유효 5건 이상일 때만 4시간 미만, 4~24시간, 1~3일, 3일 이상 구간을 표시한다.

## 개인정보·보관·권한 경계

- 지표 응답에는 업무 제목, 요청·담당·진행 ID, 회사명, 이메일, 정확한 시각을 포함하지 않는다.
- 대표 `/api/state` 응답 최상위에만 합계를 제공하며 저장 상태 원문에 파생 지표를 넣지 않는다. 파트너 응답에는 지표를 제공하지 않는다.
- 지원 요청 제목은 기존 업무 제목과 같은 저장·권한·보관 경계를 사용한다. 새 테이블이나 삭제 작업, 보관 정책을 추가하지 않는다.
- 이 지표는 현재 상태 스냅샷이다. 관리자가 업무를 상태에서 삭제하면 과거 합계에서도 빠지며, 모든 처리 주기의 장기 이력으로 해석하지 않는다.

## 검증 결과

- Node 자동 검사 237개 통과.
- 격리 workerd + 실제 D1/R2 검사 124개 통과.
- 타입검사, lint, 프로덕션 빌드 통과.
- 파트너 신규 요청의 상태·회사·시각·분류·처리자 위조 제거, 대표 인지·완료, 요청자 자가종료, 재개 주기, 분류 불변을 가상 상태로 확인했다.
- 유형·등록 주체 주변합, 대표 인지·처리·미인지 대기의 독립 공개 기준, 기존·잘못된 기록, 가상 업무 제외를 확인했다.
- 대표 전용 최상위 응답과 파트너·저장 상태 원문 비노출을 확인했다.
- 격리 검증의 외부 요청, 운영 쓰기, 메일 발송, 외부 AI 호출은 0건이다.

## Duet 검수

Duet는 완료 처리 주체가 없으면 요청자 자가종료가 대표 처리시간을 왜곡하고, 담당을 대표에게 옮기면 요청자 화면에서 요청이 사라진다고 지적했다. 서버 파생 처리자 역할과 대표 인지시각을 추가하고 요청자 소유권을 유지해 두 중대 의견을 반영했다. 잘못된 seed 근거, 전용 지표 문서, 지원 요청 회사 기본값에 관한 경미 의견도 모두 반영했다.

최종 차이 검토를 실행했으나 네이티브 Windows에서는 고위험 검수에 필요한 샌드박스 검사를 제공할 수 없어 Duet 완료 판정이 차단됐다. 합의된 중대 의견의 코드 반영과 로컬 회귀검증은 별도로 완료했으며, Duet의 전체 완료 판정으로 표현하지 않는다.

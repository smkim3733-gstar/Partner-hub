# 상담 FLOW 감사기록 원본·개수 무결성

기준일: 2026-09-06

## 보완 내용

정상 사용자 명령 또는 내부 AI 결과 전이와 무관한 감사기록을 최초 삽입이나 후속 revision에 추가할 수 있던 공백을 차단했다.

- 최초 삽입의 새 감사기록 수를 새 명령 ID 수와 정확히 일치시킨다.
- 후속 revision의 새 감사기록 수를 새 명령 ID 수와 `processing` 작업의 `blocked`·`failed`·`complete` 결과 전이 수의 합과 정확히 일치시킨다.
- 각 새 명령은 같은 ID의 감사기록과 멱등 영수증을 정확히 한 건씩 가져야 한다.
- 각 처리 결과 전이는 해당 작업에 결속된 `ai_result` 감사기록을 정확히 한 건씩 가져야 한다.
- 애플리케이션 커밋 검사와 추가형 `0068` D1 트리거 두 개가 같은 규칙을 독립적으로 강제한다.
- 기존 감사기록 접두부, 명령 의미, 행위자, 시각, AI 결과 문구와 작업 결속 경계는 그대로 유지한다.

# 자료 완료상태·AI 판정 근거 점검

2026-09-01. 사용자의 별도 `다음 진행` 요청으로 파일이 없는 요청 카드의 완료상태와 AI 사전점검 근거 사용을 점검했다. 실제 고객 파일과 외부 AI는 사용하지 않았다.

## 재현과 수정

기존 자료함은 실제 파일이 없는 서류요청 카드도 상태 선택만으로 `제출완료`·`검토완료`로 변경할 수 있었다. AI 사전점검은 진행 연결과 상태만 확인했기 때문에 이 빈 카드도 사업자등록증·재무·신용 근거로 인정했다.

- 실제 보안 저장 파일 ID가 없는 자료 카드는 `제출완료`와 `검토완료`로 변경하지 못하게 한다.
- 파일이 없는 카드에는 실제 파일 등록 후 완료상태로 변경할 수 있다는 안내를 표시한다.
- AI 사전점검 근거는 `제출완료`·`검토완료` 상태와 함께 보안 저장 파일 ID를 필수로 확인한다.
- 요청중·보완필요 자료와 상태만 바뀐 빈 카드는 판정 근거에서 제외한다.
- 실제 파일이 저장된 자료의 기존 상태 변경과 진행·담당 계정 검사는 그대로 유지한다.

서버 저장소, 자료 삭제·보존 정책, 외부 AI 동의·비용·모델은 변경하지 않았다.

## 검증과 배포

- 파일 없는 카드의 완료상태 차단, 저장 파일의 상태 변경, 상태만 완료인 자료의 AI 근거 제외를 가상 데이터로 검증했다.
- 전체 Node 검사 201개, 타입검사, lint, 빌드가 통과했다.
- 서버 API·DB 스키마를 바꾸지 않아 기존 workerd/D1/R2 저장소 검사 110개는 반복하지 않았다.
- 검사·빌드 로그는 `outputs/validation/document-evidence-tests.log`, `document-evidence-build.log`에 남겼다.
- 사용자 지침에 따라 브라우저 클릭 시험, 실제 파일 등록, 외부 AI 호출은 수행하지 않았다.
- 운영 반영 상태는 `outputs/release/document-evidence-deployment.json`에 기록한다. 기존 공개 사이트, D1/R2 연결, 추가형 마이그레이션 8개를 유지한다.

# 외부 AI 공급자 응답 검증 안전성

2026-09-03 기준으로 상담 FLOW 보고서와 가상기업 Step 0이 Anthropic 응답을 해석하는 공용 경계를 보강했다.

## 변경 범위

- 외부 응답을 `unknown`으로 읽고 일반 JSON 객체인지 확인한다.
- 응답 블록의 종류와 텍스트 형식, 완료 사유, 요청 식별값, 입력·출력 토큰 수를 검증한다.
- 텍스트 블록만 합치며 알 수 없는 공급자 필드는 내부 결과나 화면으로 전달하지 않는다.
- 미완결 응답, 비-JSON, 손상된 블록, 음수·소수 토큰 수, 과대 텍스트는 결과 저장 전에 차단한다.
- Step 0의 JSON 객체가 아닌 요청 본문은 외부 호출 전에 400으로 거절한다.
- 공급자의 오류 본문은 사용자에게 직접 노출하지 않고 HTTP 상태에 맞는 안전한 한국어 안내를 사용한다.

## 유지한 안전 경계

- AI 실행은 기존 역할·동의·비용 확인·사전점검·실행 잠금을 모두 통과해야 한다.
- 응답 검증 실패는 성공으로 저장하지 않으며 자동 재시도하지 않는다.
- 상담 FLOW 결과의 완결 표식·길이·개인정보 형식 검사와 Step 0 결과 스키마 검사를 유지한다.
- API 키·모델 설정, 프롬프트, 운영 데이터, D1/R2 스키마, 인증·권한과 보관 정책은 변경하지 않았다.

## 검증

- 자동 테스트 371개
- 격리 workerd/D1/R2 검사 129개
- TypeScript 타입검사, 전체 lint, 프로덕션 빌드
- localhost `/` HTTP 200

모든 AI 응답 테스트는 합성 응답으로 실행했다. 검증 중 실제 운영 쓰기·메일·유료 AI·외부 요청은 0건이다. GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다.

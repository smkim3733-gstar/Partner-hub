## 점검 목적

브라우저 응답은 공용 비공개 응답 경계로 보호되지만 일부 API 실패 경로가 원본 예외 객체나 예외 메시지를 운영 로그에 전달했다. 저장소·외부 공급자 예외에는 내부 경로, 쿼리 문맥 또는 입력에서 파생된 내용이 포함될 수 있으므로 필요한 장애 분류만 남긴다.

## 반영 내용

- AI 준비상태·Step 0 조회와 생성, 기업자료 업로드·다운로드·삭제, 공개 가입, 포털 상태 조회·저장의 실패 로그 9곳에서 원본 예외 객체를 제거했다.
- 손상된 Anthropic 응답 로그 1곳에서 상세 메시지를 제거했다.
- 해당 로그는 고정 작업 문맥과 `Error.name` 또는 `unknown`만 기록한다.
- 공급자 HTTP 실패의 상태와 공급자 요청 식별값 기록은 장애 추적에 필요한 비밀값 아닌 메타데이터로 유지했다.
- 서버 로그에 원본 예외, `message`, `stack`, `cause`가 다시 전달되면 실패하는 정적 회귀검사를 추가했다.

화면에 반환하는 안전한 한국어 오류, HTTP 상태, 재시도 정책, D1/R2 처리, AI 비용·동의 경계는 변경하지 않았다.

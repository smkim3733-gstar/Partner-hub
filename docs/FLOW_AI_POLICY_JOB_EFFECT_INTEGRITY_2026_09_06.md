# 상담 FLOW AI 정책 작업 효과 무결성

기준일: 2026-09-06

## 보완 내용

`set_ai_policy` 명령이 AI 정책 필드와 작업 목록을 함께 바꿀 수 있는 허용 범위를 정확한 업무 효과로 좁혔다.

- 자동생성을 중지하면 기존 `queued` 작업만 `blocked`로 바꾸고 사유를 `대표가 자동생성을 중지했습니다.`로 고정한다.
- 중지 시 이미 처리 중이거나 완료·실패·보류된 작업은 그대로 보존한다.
- 자동생성을 허용할 때는 기존 작업의 상태·사유·시각·증거를 변경하지 않는다.
- 정책 명령으로 작업을 추가·삭제·재정렬하거나 다른 상태 전이를 함께 처리할 수 없다.
- 애플리케이션 커밋 검사가 D1 쓰기 전에 기존 작업 전체와 예상 결과를 정확히 비교한다.
- 추가형 `0071` D1 트리거가 앱 경로를 우회한 직접 SQL에도 같은 규칙을 강제한다.

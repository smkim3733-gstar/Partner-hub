# 상담 FLOW 2슬롯 R2 결과 불명 복구 무결성

기준일: 2026-09-06

## 확인한 위험

전사문과 보조 음성 두 객체가 모두 R2에 저장됐지만 두 번째 쓰기의 성공 응답만 유실되면 FLOW 본문은 아직 커밋되지 않은 채 두 객체가 남는다. 재시도가 새 파일 ID나 키를 만들거나 한 슬롯만 완료하면 중복·연결 불일치가 발생할 수 있다.

## 확인한 현재 경계

- 첫 R2 쓰기 성공과 두 번째 R2 실제 저장 직후 응답 유실을 결정적으로 재현했다.
- 응답은 내부 오류를 숨긴 503과 동일 자료 재시도 안내만 반환한다.
- 기존 FLOW 본문은 변경하지 않고 두 R2 객체와 두 `pending` 예약을 모두 보존한다.
- 새 명령 ID의 같은 전사문·음성 재시도는 두 예약의 기존 파일 ID와 R2 키를 재사용한다.
- 완료 뒤 객체 수는 두 개로 유지되고 두 예약은 `ready`, 각 완료 원장은 실제 성공 명령 ID를 기록한다.

기존 구현이 요구 경계를 만족해 런타임 코드는 바꾸지 않고 2슬롯 회귀 증거를 추가했다.

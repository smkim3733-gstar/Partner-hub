# 상담 FLOW 명령 의미 무결성

기준일: 2026-09-06

## 문제·적용

새 명령 ID·감사기록·영수증은 함께 저장됐지만, 영수증의 행위자 표시와 명령 동작을 별도로 보존하지 않아 같은 ID 아래 서로 다른 의미의 정상 모양 값을 결합할 수 있었다. 이제 새 영수증에 감사 행위자와 동작을 함께 저장하고, 애플리케이션과 추가형 `0053` D1 트리거가 같은 ID 감사기록의 값과 일치시키며 이후 변경도 차단한다.

## 감사·보존 경계

- 새 명령 영수증은 `actorKey`, 요청 지문, 감사 행위자 표시, 감사 동작을 함께 보존한다.
- 영수증의 행위자 표시와 동작은 같은 명령 ID·같은 revision의 감사기록과 정확히 일치해야 한다.
- 한 번 저장된 영수증의 행위자 표시와 동작은 후속 직접 SQL에서도 변경할 수 없다.
- 신규 FLOW 행에 명령이 있으면 모든 명령의 감사·영수증 의미가 최초 수정시각에 결속돼야 한다.
- 기존 레거시 영수증의 새 필드 부재는 읽기 호환하며 후속 저장에서 임의로 보충하지 않는다.
- 영수증 전체는 파트너·관리자 API 응답에서 계속 제외해 내부 행위자 키와 요청 지문을 노출하지 않는다.

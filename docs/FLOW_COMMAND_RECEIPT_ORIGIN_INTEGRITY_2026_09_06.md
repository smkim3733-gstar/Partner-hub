# 상담 FLOW 명령 영수증 생성시점 무결성

기준일: 2026-09-06

## 문제·적용

새 명령에는 즉시 영수증이 필요하고 기존 영수증은 불변이었지만, 영수증 없이 남은 과거 레거시 명령 ID에 후속 revision에서 임의 영수증을 덧붙일 수 있었다. 그러면 요청 지문과 행위자 근거를 사후 작성해 재시도 판정에 사용할 수 있다. 이제 애플리케이션과 추가형 `0052` D1 트리거가 새 영수증을 같은 revision에 추가된 새 명령 ID에만 허용한다.

## 감사·보존 경계

- 기존 명령 ID에 영수증이 없더라도 후속 저장에서 임의로 보충할 수 없다.
- 새 영수증 키는 같은 revision의 `commandIds` 새 접미부에 포함돼야 한다.
- 새 명령 ID는 기존 `0051` 경계에 따라 같은 revision에 감사기록과 영수증을 모두 가져야 한다.
- 기존 영수증의 행위자 키·요청 지문 수정과 삭제는 계속 차단한다.
- 과거 레거시 자료는 읽기 호환하되 재시도 성공 근거를 새로 만들지 않는다.

# 상담 FLOW AI 결과 파일 무결성

기준일: 2026-09-06

## 보완 내용

운영 AI 실행은 생성 텍스트를 보고서와 작업 상태에 같은 트랜잭션으로 저장하고 별도 결과 파일을 만들지 않는다. 그런데 내부 완료 함수의 미사용 파일 옵션과 비명령 전이 허용 범위 때문에 정상 AI 완료에 임의 파일 메타데이터와 보고서 `fileId`를 섞을 수 있던 공백을 차단했다.

- `finishFlowJob`의 사용되지 않는 결과 파일 입력과 파일 추가 코드를 제거했다.
- AI 완료는 기존 `files` 배열을 그대로 보존한다.
- 새 AI 결과 보고서는 `fileId`를 포함할 수 없다.
- 애플리케이션 커밋 검사와 추가형 `0063` D1 트리거가 같은 규칙을 독립 검사한다.
- 향후 실제 결과 파일 생성 기능이 필요하면 R2 객체 쓰기, 소유권·메타데이터·ETag 원장과 FLOW 완료를 하나의 검증 경계로 새로 설계해야 한다.

## 검증·배포

- 정상 완료 결과에 형식상 유효한 PDF 파일 메타데이터와 보고서 `fileId`를 주입하는 앱·D1 변조를 거절했다.

# 업로드 파일 형식 공용 등록표

## 목적

업로드 허용 확장자, 저장 MIME, 다운로드 MIME, 실제 내용 판정과 화면 파일 선택 목록이 서로 다른 하드코딩 목록으로 어긋나지 않도록 공용 형식 등록표를 사용한다.

## 적용 범위

- 지원 확장자별 고정 MIME과 실제 내용 판정 종류를 `UPLOAD_FILE_FORMATS` 한곳에 선언한다.
- 다운로드 MIME과 상담 FLOW 저장 MIME은 같은 등록값을 사용한다.
- 기업자료·녹취자료·기업자료함 파일 선택 `accept` 값은 등록된 확장자 배열에서 생성한다.
- 실제 파일 형식 검사는 파일명 확장자를 공용 파서로 읽고 등록표의 판정 종류를 사용한다.
- 등록되지 않은 확장자는 기존 fail-closed 원칙에 따라 거절한다.

## 유지한 경계

현재 허용 형식과 목적별 허용 범위, 파일 내용·크기·이름·R2 키, 인증·권한·동의, D1/R2 스키마와 보관 정책은 변경하지 않았다. 기업자료함 화면의 선택 가능 형식과 안내 문구도 동일하다.

## 재발 방지

13개 지원 확장자의 MIME·대소문자 확장자 판독·다운로드 MIME 일치, 기업자료·녹취·통합 파일 선택값과 화면의 공용 상수 사용을 자동 테스트로 고정했다.

## 검증 결과

- 관련 형식·업로드·다운로드·화면 회귀검사 42개 통과
- 전체 자동 테스트 449개 통과
- 격리 workerd/D1/R2 검사 129개 통과
- TypeScript 타입검사, 전체 lint, 프로덕션 빌드 통과
- 격리검사 중 운영 쓰기, 메일, 유료 AI, 외부 요청 0건

# 협업신청 첨부 자료종류 확인 안전성

2026-09-03 기준. 협업신청의 기업 기본자료 첨부가 파일명 추정만으로 확정·제출되지 않도록 파일별 자료종류 확인을 추가한 기록이다.

## 확인한 문제

- 기업 기본자료는 파일명의 `사업자`, `크레탑`, `재무`, `특허` 같은 단어로 자료종류를 자동 확정했다.
- 추정 결과는 목록에 표시됐지만 사용자가 실제 파일과 일치하는지 확인하지 않아도 신청을 제출할 수 있었다.
- 잘못된 종류는 접수 자료 목록과 이후 AI 사전점검의 필수 근거 분류에 영향을 줄 수 있었다.

## 적용한 동작

- 기업 기본자료의 파일명 분류 결과는 자동 확정이 아닌 제안 상태로 추가한다.
- 첨부마다 현재 자료종류를 선택할 수 있고 `현재 파일의 자료종류 확인`을 직접 체크해야 한다.
- 종류를 바꾸면 확인을 해제해 변경된 선택을 다시 확인하도록 한다.
- 확인되지 않은 파일이 하나라도 있으면 첫 파일명을 포함한 오류로 신청 제출을 차단한다.
- 녹취자료 전용 입력에서 고른 파일은 입력 경로 자체가 자료 성격의 명시 선택이므로 확인 상태로 추가한다.
- 첨부 목록이나 확인 상태가 바뀌면 기존처럼 자료제출·녹취 동의를 다시 확인한다.

## 운영 경계

- 파일명 분류는 편의용 제안으로만 유지하며 사실 판정으로 사용하지 않는다.
- 이미 서버에 저장된 파일의 종류를 변경하거나 재분류하지 않는다.
- 첨부파일과 종류 확인 상태는 기존처럼 신청 임시저장 복구 대상이 아니며 재접속 뒤 파일을 다시 선택해야 한다.
- 자료종류의 기존 의미, 녹취 동의, AI 사전점검, 서버 API, DB/R2 스키마, 인증·권한·보관 정책은 변경하지 않았다.
- 실제 운영 데이터 쓰기, 메일 발송, 유료 AI 호출, 외부 요청은 검증 중 모두 0건이다.

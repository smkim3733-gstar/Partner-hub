# 협업신청 첨부 내용 확인 중 제출 잠금 정책

## 목적

협업신청에서 새로 선택한 첨부의 실제 바이트 지문 계산이 끝나기 전에 제출·임시저장·화면이동이 실행되어 방금 고른 파일이 누락되는 경합을 차단한다.

## 변경 전 위험

첨부 컴포넌트 안의 두 파일 입력은 SHA-256 계산 중 잠겼지만, 부모 폼의 제출·임시저장·이전·취소 버튼은 그 상태를 알지 못했다. 사용자가 파일을 고른 직후 계산 완료 전에 제출하면 부모 상태에는 아직 새 첨부가 없어 해당 파일 없이 신청이 저장될 수 있었다.

## 적용 내용

- 첨부 컴포넌트가 파일 내용 확인 시작·종료 상태를 부모 신청 폼에 전달한다.
- 부모는 React 상태와 동기 ref를 함께 사용해 화면 버튼과 제출 함수 양쪽에서 경합을 차단한다.
- 내용 확인 중 제출·임시저장·이전·취소 버튼을 잠그고 제출 버튼에 `첨부 내용 확인 중`을 표시한다.
- 정상 완료 또는 파일 판독 실패 시 `finally`에서 자식·부모 잠금을 함께 해제한다.
- 첨부 판독 후 자료종류와 제출 동의를 다시 확인해야 하는 기존 규칙을 유지한다.

## 유지한 경계

서버 API, D1/R2 스키마, 업로드 멱등키, 파일 형식·크기·개수·권한 검증, 원본 보관·삭제 정책은 변경하지 않았다. 운영 고객 파일을 읽거나 전송하지 않았다.

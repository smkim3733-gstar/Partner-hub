# 격리 가상 데이터 화면 점검

2026-09-01. 사용자는 로컬 가상 데이터로 로그인·신청·첨부·상담 FLOW 화면을 점검하는 준비안에 「진헹」으로 진행을 승인했다. 기존 자동 순차 점검 3항목과 별도의 수동 점검이며 자동 실행을 재개하지 않았다.

## 환경과 경계

- 현재 빌드의 Worker·정적 화면을 localhost에서 실행했다. Miniflare의 새 메모리 전용 D1/R2를 사용했으며 기존 로컬 DB 및 운영 DB/R2를 읽거나 복제하지 않았다.
- 파트너는 `example.invalid` 도메인의 가상 계정과 가상 비밀번호만 사용했다. 대표 화면은 localhost에서만 허용되는 가상 Sites 신원 헤더로 확인했다. 실제 대표 SSO 인증 검증으로 해석하지 않는다.
- 외부 요청 차단, 외부 요청 0건. 실제 계정 등록·고객 자료 열람·연락·메일·유료 AI·삭제·보관 정책 변경은 수행하지 않았다.
- 시험 보조 스크립트와 가상 파일은 Git 제외 경로 `work/`, `outputs/validation/`에 두었다. 운영 빌드에 포함하지 않는다.

## 재현한 문제와 수정

1. 파트너 첫 화면이 DB에 기업·업무가 없어도 고정된 예시 기업 3건과 업무·수치를 표시했다. 서버가 허용한 기업·업무·자료로 목록과 수치를 계산하도록 연결하고 빈 목록 안내를 표시했다. 대표의 파트너 미리보기는 담당 계정 ID로 분리한다. 기업·업무를 선택하면 해당 진행을 열고, 연결된 진행이 없는 업무는 업무 목록을 연다.
2. FLOW 저장 응답이 JSON이 아닌 경우 개발용 파싱 오류가 화면에 표시됐다. 입력을 유지하고 같은 요청 재시도 또는 최신 진행 확인을 안내하는 한국어 문구로 변경했다. 요청 식별값·권한·서버 저장 로직은 변경하지 않았다.

수정본에서 기업 0건인 빈 상태와 가상기업 2건·상담 단계 1건·미완료 업무 1건인 상태를 각각 확인했다. HTML 503 응답 뒤 한국어 안내와 동일 요청 재시도, 보고서 이력 1건을 다시 확인했다.

## 검증 및 반영 기록

- 타입검사, lint, 빌드 통과. Node 테스트 183개 및 격리 workerd/D1/R2 검사 110개 통과.
- 처음 빌드는 실행 중인 로컬 출력 파일 잠금으로 실패했다. 점검 서버를 종료한 후 동일 명령으로 빌드에 성공했다. 격리 회귀검증의 번들러 파일 읽기 제한은 승인된 실행 권한으로 재검증하여 통과했다.
- 가상 런타임 기록: `outputs/validation/ui-pilot-first-pass.json`, `ui-pilot-runtime.json`. 검사 로그: `ui-pilot-node-tests.log`, `ui-pilot-worker-tests.log`, `ui-pilot-build.log`.
- 이 문서는 코드·로컬 검증 기록이다. 기존 사이트 반영 여부와 확정된 소스·배포 정보는 `outputs/release/ui-screen-deployment.json`의 실제 결과를 기준으로 한다. 기존 공개 범위와 DB/R2 연결, 마이그레이션 8개를 유지한다.
- 실제 파트너 실사용, 실제 대표 SSO, 키보드 전용 조작, 모든 FLOW 후반 단계의 브라우저 시험은 완료로 표시하지 않는다. 자동 실행은 일시 중지 상태를 유지한다.

# 기업자료 종류 명시 선택 안전성

2026-09-03 기준. 기업자료함의 단일 원본파일 등록에서 자료종류를 실제 파일에 맞게 직접 선택하도록 보완한 기록이다.

## 확인한 문제

- 새 기업자료 등록창이 자료종류를 항상 `사업자등록증`으로 시작했다.
- 사용자가 종류를 확인하지 않고 등록하면 크레탑·재무제표·기타자료가 사업자등록증으로 잘못 분류될 수 있었다.
- 음성·녹취로 추정되는 파일명은 화면에서 `녹취자료`로 자동 변경되어 현재 파일에 대한 직접 선택이 생략됐다.
- 잘못된 분류는 자료 목록뿐 아니라 이후 검토와 AI 사전점검의 자료종류 판단에도 영향을 줄 수 있다.

## 적용한 동작

- 새 등록창과 성공·취소 후 초기화 상태의 자료종류를 빈 값으로 통일한다.
- 첫 선택항목에 `자료종류 선택`을 표시하고 실제 종류를 직접 골라야 한다.
- 파일명으로 녹취자료를 자동 확정하지 않는다.
- 빈 값과 허용 목록 밖의 값은 기존 공용 메타정보 검증이 화면과 서버에서 업로드 전에 거절한다.
- 종류·파일 등 입력이 바뀌면 기존처럼 제출 권한과 개인정보 마스킹 동의를 다시 확인한다.

## 운영 경계

- 기존 저장자료의 종류를 일괄 수정하거나 추정하지 않는다.
- 사업자등록증·크레탑·재무제표·녹취자료 등 기존 종류의 의미와 AI 사전점검 기준은 바꾸지 않았다.
- 협업신청의 여러 첨부파일 분류 경로는 이번 변경 범위가 아니다.
- 서버 API, DB/R2 스키마, 인증·권한·보관 정책은 변경하지 않았다.
- 실제 운영 데이터 쓰기, 메일 발송, 유료 AI 호출, 외부 요청은 검증 중 모두 0건이다.

## 검증 결과

- 빈 초기 자료종류와 공용 저장 경계의 거절 회귀검사 추가.
- 관련 테스트 6개 통과.
- 전체 자동 테스트 285개 통과.
- 격리 workerd/D1/R2 검사 129개 통과.
- 타입검사, 전체 lint, `git diff --check`, 프로덕션 빌드 통과.
- 실행 중인 localhost `/` 응답 HTTP 200 확인.

GitHub `main` 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다.

# 상담 FLOW 새 명령 증거 무결성

기준일: 2026-09-06

## 문제·적용

기존 명령 이력과 AI 작업의 생성 명령 연결은 보존됐지만, 일반 사용자 명령 ID를 새로 추가하면서 같은 ID의 감사기록이나 멱등 영수증을 누락할 수 있었다. 이제 애플리케이션과 추가형 `0051` D1 트리거가 모든 새 명령 ID를 같은 revision의 새 감사기록 하나와 불변 명령 영수증에 결속한다.

## 감사·보존 경계

- 새 `commandIds` 항목마다 같은 ID의 `ai_result`가 아닌 감사기록이 정확히 하나 있어야 한다.
- 새 감사기록의 시각은 해당 FLOW revision의 권위 수정시각과 같아야 한다.
- 새 명령 ID마다 행위자 키와 요청 지문을 가진 명령 영수증이 함께 추가돼야 한다.
- 기존 명령 ID·영수증은 순서와 값을 유지하며 수정·삭제할 수 없다.
- 신규 FLOW 행도 처음부터 포함한 모든 명령 ID에 같은 증거 규칙을 적용한다.
- 기존 레거시 명령 ID의 증거 부재는 읽기 호환하며 운영 자료를 다시 쓰지 않는다.

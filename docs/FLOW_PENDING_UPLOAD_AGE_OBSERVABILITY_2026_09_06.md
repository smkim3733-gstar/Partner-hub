# 상담 FLOW 미완료 첨부 출처·연령 관측 경계

기준일: 2026-09-06

## 확인한 문제

대표 전용 원본 보관 현황은 일반 기업자료 업로드 대기와 상담 FLOW 첨부 예약을 같은 `pending` 상태로 보여 줬다. 생성시각은 표시했지만 어느 저장 경로에서 생긴 기록인지와 얼마나 오래 미완료인지 바로 구분하기 어려워, 같은 신청 재시도와 상담 FLOW 재시도 안내가 섞였다.

## 보완

- 인벤토리 응답에 `company`와 `flow` 두 값만 허용하는 출처 필드를 추가한다.
- 대표 화면은 `기업자료 업로드`와 `상담 FLOW 첨부 예약`을 명시적으로 구분한다.
- 이미 검증된 생성시각과 목록 조회시각만 사용해 미완료 경과를 `4시간 미만`, `4~24시간`, `1~3일`, `3일 이상`의 겹치지 않는 구간으로 표시한다.
- 생성시각이 손상됐거나 조회시각보다 미래면 경과를 추정하지 않고 `경과 확인 필요`로 표시한다.
- 3일 이상인 상담 FLOW 예약은 담당 파트너에게 저장 완료 여부와 동일 파일 보유 여부를 확인한 뒤 해당 상담 화면에서 재시도하도록 강조한다.
- 3일 미만인 상담 FLOW 예약은 같은 상담 화면에서 동일 명령·동일 파일로 재시도하고, 새로고침했다면 동일 파일을 다시 선택하도록 안내한다.

## 개인정보·운영 경계

- 연령은 목록에 이미 포함된 생성시각과 조회시각에서 화면이 계산한다. 새 활동시각·사용자 행동 추적·파일 본문을 수집하지 않는다.
- 응답은 출처 열거값만 추가하며 R2 저장 키, 명령 ID·지문, 보고서·녹취 본문을 반환하지 않는다.
- 목록과 원본 존재 확인은 계속 대표 관리자만 사용할 수 있다. 파트너·비로그인 사용자의 조회 권한을 넓히지 않는다.
- 이 화면은 장기 예약도 자동 연결·자동 삭제·자동 만료하지 않는다. 보관·삭제 정책과 기존 원장 수명주기는 변경하지 않는다.

## 회귀 검증

- 일반 업로드 대기와 상담 FLOW 예약이 각각 정확한 출처 열거값으로 반환되는지 확인했다.
- 허용되지 않은 출처값이 성공 응답으로 화면에 들어오지 못하는지 확인했다.
- 4시간·24시간·3일 경계 직전과 정확한 경계가 한 구간에만 속하는지 확인했다.
- 미래 생성시각을 경과 구간으로 추정하지 않는지 확인했다.
- 상담 FLOW 미완료 항목이 안전한 파일 메타데이터만 반환하고 저장 키·행위자 키·명령 ID·지문은 노출하지 않는 기존 검사를 유지했다.
- Node 709/709, 격리 workerd+D1+R2 521/521, 타입검사, 전체 lint, 변경 파일 포맷과 프로덕션 빌드를 통과했다.
- 로컬 Worker의 `/`, `/account`, `/account/setup`은 200, 비로그인 `/api/state`, `/api/admin/file-inventory`, `/api/consulting-flow/test-case`는 401과 `private`, `no-store`, `nosniff` 경계를 반환했다.
- 격리 검증의 운영 쓰기, 메일, 유료 AI, 외부 요청은 모두 0건이다.

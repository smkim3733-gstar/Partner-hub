# 상담 FLOW 관리자 명령 행위자 신원 무결성

기준일: 2026-09-06

## 문제·적용

관리자 명령 영수증의 행위자 키가 관리자 이메일을 사용해 이메일 변경 시 동일 요청 재시도 신원이 달라지고, 직접 저장 경로에서는 임의 `admin:` 식별자를 새 관리자 명령 근거로 넣을 수 있었다. 이제 새 관리자 명령은 이메일이나 공급자 표시값 대신 단일 논리 관리자 신원 `admin:primary`를 사용하고 애플리케이션과 추가형 `0056` D1 트리거가 다른 관리자 키를 거절한다.

## 감사·보존 경계

- 새 관리자 명령 영수증은 정확히 `admin:primary` 행위자 키를 사용한다.
- 이메일 변경과 무관하게 같은 관리자 명령의 멱등 재시도 신원을 유지한다.
- 앱 저장 경로와 직접 D1 삽입·갱신 경로에 같은 조건을 적용한다.
- 기존 이메일 기반 관리자 영수증은 읽기·재시도 호환을 유지하며 후속 revision에서 변경하지 않는다.
- 대표 역할 인증과 안정 ChatGPT 결속은 기존 인증 경계에서 먼저 확인한다.

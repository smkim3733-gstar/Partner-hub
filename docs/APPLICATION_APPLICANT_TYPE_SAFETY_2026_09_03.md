# 협업신청 신청자 유형 안전성

2026-09-03 기준. 대표 대리접수의 신청자 유형이 자동 확정되거나 공유 계정과 다르게 저장되지 않도록 보완한 기록이다.

## 확인한 문제

- 대표가 새 협업신청을 대리 접수하면 신청자 유형이 `한기평 컨설턴트`로 자동 선택됐다.
- 공유 계정을 선택한 뒤 신청자 이름이나 공유 계정을 바꿔도 이전 계정의 유형이 남을 수 있었다.
- 공유 계정이 연결된 상태에서도 신청자 유형을 별도로 바꿀 수 있어 계정의 등록 유형과 신청 기록이 달라질 수 있었다.
- 임시저장은 미완성 신청을 허용하지만 신청자 유형만 빈 값으로 저장할 수 없어 안전한 빈 시작과 맞지 않았다.

## 적용한 동작

- 대표 대리접수는 신청자 유형이 빈 상태로 시작하며 허용된 네 유형 중 하나를 직접 골라야 1단계를 통과한다.
- 일반 파트너의 신청은 현재 로그인 계정에 등록된 유형을 읽기 전용으로 적용한다.
- 대표가 자료 공유 계정을 고르면 해당 활성 계정의 등록 유형을 적용하고 유형 선택을 잠근다.
- 신청자 이름을 직접 바꾸거나 대표 전용 접수로 돌아가면 공유 계정과 이전 유형을 함께 비운다.
- 공유 계정이 없는 대표 임시저장의 유형은 재접속 시 다시 선택한다. 계정이 명시적으로 연결된 임시저장만 저장 유형을 복구한다.
- 단계 이동과 최종 제출 직전에 빈 값·임의 유형을 거절하고, 연결 계정의 현재 활성 상태와 등록 유형을 다시 대조한다.
- 제출에는 화면 상태가 아닌 공용 검증 함수가 반환한 신청자 유형만 사용한다.

## 운영 경계

- 기존 접수와 파트너 계정 유형을 일괄 변경하지 않는다.
- 임시저장 JSON은 미완성 대리접수를 위해 빈 유형을 허용하지만 최종 제출은 허용하지 않는다.
- 공유 계정의 접근권한, 신청자 유형 의미, 기존 신청 상세, 서버 API, DB/R2 스키마와 보관 정책은 변경하지 않았다.
- 실제 운영 데이터 쓰기, 계정 변경, 메일 발송, 유료 AI 호출, 외부 요청은 검증 중 모두 0건이다.

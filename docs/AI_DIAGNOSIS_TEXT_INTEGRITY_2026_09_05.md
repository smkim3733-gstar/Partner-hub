# AI 진단 문자열 무결성 경계

기준일: 2026-09-05

## 문제

AI 진단 실행 필드와 완료 결과는 길이·구조·저장 용량을 제한했지만, 화면에 표시하거나 후속 처리하기 부적합한 제어문자, 짝이 없는 UTF-16 surrogate, 대체문자 `U+FFFD`를 명시적으로 거절하지 않았다. 애플리케이션 경로와 D1 직접 SQL의 처리 차이가 생기면 실행 신원·감사 결과가 손상된 문자열로 저장될 수 있었다.

## 적용

- 공용 `isSafeStoredText` 경계가 짝이 없는 UTF-16 surrogate, C0 제어문자(탭·줄바꿈·캐리지리턴 제외), C1 제어문자와 `U+FFFD`를 거절한다.
- 정상 줄바꿈, 탭과 올바른 surrogate 쌍으로 표현된 이모지는 유지한다.
- Step 0 요청·준비상태는 안전하지 않은 모델 환경값을 미설정으로 처리하고 외부 AI 호출 전에 HTTP 503으로 종료한다.
- 실행 잠금 저장, 완료 결과 파서와 클라이언트 응답 경계가 같은 문자열 계약을 사용한다.
- `0037_ai_diagnosis_text_envelope.sql`과 런타임 준비 트리거가 신규 실행 신원과 완료 결과의 모든 JSON 문자열에도 같은 계약을 강제한다.
- 기존 실행 원장은 바꾸지 않고 이후 신규 삽입·완료 전이만 보호한다.

## 검증

- 파서와 응답 경계가 짝 없는 surrogate, C0 제어문자와 `U+FFFD`를 거절한다.
- 실행 저장 함수와 D1 직접 삽입이 손상된 기업명·모델·신원 문자열을 거절한다.
- D1 직접 완료 전이도 중첩 결과 문자열의 손상 Unicode를 거절한다.
- 안전하지 않은 모델 설정은 외부 AI 요청 전에 차단된다.
- 38개 추가형 마이그레이션을 기존 상태가 있는 격리 D1에 반복 적용해도 기존 상태를 교체하지 않는다.
- Node 회귀 검사 642/642 통과
- 격리 workerd/D1/R2 검사 449/449 통과
- 타입검사, 전체 lint, 변경 파일 포맷, 프로덕션 빌드 통과
- 로컬 운영 Worker `/`, `/account`, `/account/setup` HTTP 200과 CSP, `X-Frame-Options: DENY`, `nosniff`, `no-referrer` 확인
- 실제 운영 쓰기, 이메일 발송, 유료 AI 요청, 외부 요청 0건

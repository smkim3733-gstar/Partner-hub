# 상담 FLOW AI 성공 증거·완료 감사 결속

기준일: 2026-09-06

## 문제·적용

완료 작업은 요청 ID·요청/응답 모델·Message ID·토큰 사용량을 보존했지만 공급자 성공 응답을 관측한 시각과 완료 감사기록의 직접 연결이 없었다. 이제 성공 응답을 검증한 직후 UTC 관측시각을 만들고, 영속 저장 단계에서 완료 `ai_result` 감사 ID를 증거에 결속한다.

## 저장·검증 경계

- 성공 증거 관측시각은 작업 시작시각 이상, 완료시각 이하만 허용한다.
- 연결 감사기록은 같은 작업 ID·완료시각으로 만든 ID, `보고서 자동생성` 실행자, `ai_result` 동작과 정확한 완료시각을 모두 만족해야 한다.
- 과거 실패 뒤 성공한 작업은 성공 증거와 실패 이력이 서로 다른 감사 ID를 사용해야 한다.
- 외부 응답 처리기는 공급자 관측 사실만 만들고 영속 저장 함수가 서버 권위 감사 ID를 추가한다.
- 상세 조회는 전체 payload 관계를, 대시보드는 성공 형식·실패 형식·성공 감사·실패 감사를 나눈 4개 D1 쿼리로 검증한다. 이 분리는 D1 표현식 깊이 한계 안에서 실패 폐쇄를 유지한다.
- 기존 증거 없는 완료 작업은 계속 읽을 수 있다. 새 완료 작업은 완전한 성공 증거 없이는 정식 보고서로 저장하지 않는다.

# 사이트 인증 응답 검증 안전성

2026-09-04 기준으로 사이트 전용 가입·로그인·비밀번호 설정·로그아웃 API 응답의 클라이언트 검증을 보강했다.

## 변경 범위

- 모든 인증 응답을 `unknown`으로 읽고 일반 JSON 객체인지 먼저 확인한다.
- 로그인과 로그아웃은 HTTP 200과 명시적 `ok: true`가 함께 있을 때만 성공으로 처리한다.
- 가입 신청은 HTTP 201, 비밀번호 설정은 HTTP 200과 길이가 제한된 비어 있지 않은 완료 안내가 함께 있을 때만 폼을 비우고 완료 화면을 표시한다.
- 작업과 다른 성공 상태·필드, 거짓 성공값, 비어 있거나 과대한 안내문을 완료로 처리하지 않는다.
- 검증된 `ok` 또는 안내문만 새 객체로 반환한다. 알 수 없는 응답 필드는 인증 화면 상태로 전달하지 않는다.
- 실패 응답은 길이가 제한된 서버 오류만 유지한다. 비-JSON 응답은 게이트웨이 원문을 숨기고 재시도를 안내한다.
- 파트너 로그아웃과 ChatGPT 로그인 전 기존 사이트 세션 정리에도 같은 로그아웃 응답 검증을 적용한다.

## 유지한 안전 경계

- 서버의 HTTPS·동일 출처 검사, 가입 입력·비밀번호 정책, 속도 제한, scrypt 해시와 세션 쿠키 처리는 변경하지 않았다.
- 대표 승인 전 로그인 차단, 정지·삭제·이메일 변경 시 세션 차단, 일회용 설정 링크와 기존 세션 폐기를 유지한다.
- 응답 검증은 서버가 발급한 HttpOnly 세션 값을 읽거나 저장하지 않는다.
- 실제 계정, 운영 데이터, D1/R2 스키마, 권한·보관 정책과 공개 배포 상태를 변경하지 않았다.

## 검증

- 자동 테스트 391개
- 격리 workerd/D1/R2 검사 129개
- TypeScript 타입검사, 전체 lint, 프로덕션 빌드
- localhost `/` HTTP 200

모든 신규 응답 검사는 가상 계정과 합성 응답으로 실행했다. 실제 가입·로그인·비밀번호 변경·운영 쓰기·메일·유료 AI·외부 요청은 0건이다. GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다.

# 상담 FLOW 일정 완료 효과 무결성

기준일: 2026-09-06

`complete_meeting` 명령을 영수증에 기록한 `targetId`의 예정 상담 정확히 한 건에 결속했다. 명령 지문이 요청한 상담 ID와 내용을 묶는 기존 경계에 더해, 서버가 같은 상담 ID를 별도 영수증 필드로 저장하므로 저장 결과만 검사하는 애플리케이션과 D1도 선택 대상을 독립 확인할 수 있다. 다른 action에는 `targetId`를 허용하지 않고, 저장된 대상 이력은 이후 revision에서 바꿀 수 없다.

애플리케이션 커밋 검사와 추가형 `0082` D1 트리거 네 개는 대상 상담이 직전 상태에서 `scheduled`이고 완료시각이 없었는지, 결과가 `completed`와 현재 서버 수정시각을 가졌는지 검증한다. 일정 배열의 길이·순서·비대상 상담을 보존하고 대상에서는 상태·완료시각·메모 외 필드를 바꾸지 못하게 한다. 미래 상담 완료, 기존 메모 삭제, 완료된 상담 재완료, 영수증 대상 바꿔치기, 비참석 파트너의 완료 기록을 거절한다. 초회상담은 최신 1차 보고서 공동분석과 2차·3차 준비가 끝나고 대기·처리 중인 1차 작업이 없어야 한다.

검증은 방어 전 이미 완료된 상담의 완료시각과 메모를 다시 쓰는 위조가 수락되는 실패를 먼저 재현했다. 보완 후 정상 완료와 대상 바꿔치기·재완료·대상 누락·비참석자 기록·과거 영수증 대상 변조를 앱과 D1 양쪽에서 확인했다. Node 687/687, 관련 FLOW 검사 135/135, 집중 검사 93/93, 격리 workerd+D1+R2 509/509, 타입검사, lint, 포맷, 프로덕션 빌드, 로컬 Worker 화면 3곳 200·보호 API 3곳 401과 비공개 무저장 헤더를 통과했다. 검증 중 운영 데이터 쓰기·메일·유료 AI·외부 업무 API 호출은 0건이다.

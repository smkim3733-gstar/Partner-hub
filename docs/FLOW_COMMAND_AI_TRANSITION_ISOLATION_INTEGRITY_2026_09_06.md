# 상담 FLOW 사용자 명령·내부 AI 전이 분리 무결성

기준일: 2026-09-06

## 보완 내용

정상 사용자 명령과 내부 AI 작업 청구·결과 전이를 같은 FLOW revision에 함께 넣을 수 있던 공백을 차단했다.

- 새 사용자 명령이 있는 revision은 기존 대기 작업을 `processing`으로 청구할 수 없다.
- 새 사용자 명령이 있는 revision은 기존 처리 중 작업을 `blocked`·`failed`·`complete` 결과로 바꿀 수 없다.
- 사용자 명령 감사·영수증과 자동생성 결과 감사의 실행 주체·revision 경계를 분리한다.
- 애플리케이션 커밋 검사가 명령 수와 기존 작업 전이를 함께 비교해 D1 접근 전에 거절한다.
- 추가형 `0070` D1 트리거가 앱 경로를 우회한 직접 SQL에도 같은 분리 규칙을 강제한다.
- 사용자 재시도·AI 정책 중지처럼 명시적 명령이 담당하는 다른 작업 전이와 명령 없는 정상 AI 처리 흐름은 유지한다.

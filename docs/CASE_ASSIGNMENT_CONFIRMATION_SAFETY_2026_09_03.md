# 진행 담당 계정 변경 확인 안전성

2026-09-03 기준. 대표 진행판에서 담당 파트너 선택이 즉시 접근 계정을 바꾸던 경계를 보완했다.

## 문제

- 진행 카드의 담당 계정을 선택하면 즉시 `partnerMemberId`가 바뀌고 상위 자동저장이 시작됐다.
- 잘못 선택해도 변경 전·후 계정을 대조하거나 취소할 단계가 없었다.
- 담당 변경은 해당 진행과 타임라인의 파트너 조회범위에 영향을 주므로 일반 필터 선택보다 명확한 확인이 필요했다.

## 변경

- 담당 계정 선택은 진행 상태를 바꾸지 않고 변경 초안만 만든다.
- 별도 확인창에 기업명·현재 담당·변경 후 담당 이름과 이메일을 표시한다.
- `취소`와 닫기는 초안을 폐기하고 원래 담당을 유지한다.
- `담당 변경 저장`을 누를 때 진행 ID, 변경 전 담당 ID, FLOW 자동관리 여부와 새 계정의 현재 활성 상태를 다시 검사한다.
- 검토 중 다른 화면에서 담당이 바뀌었거나 대상 계정이 정지·삭제되면 변경을 거절하고 최신 화면에서 다시 선택하도록 안내한다.
- 기존 원본파일·업무·자료 담당은 자동 이전되지 않는 기존 보안 경계를 확인창에 명시한다.

## 유지한 경계

- 상담 FLOW가 이미 관리하는 진행의 담당을 수동 변경할 수 없는 기존 규칙을 유지한다.
- 기존 원본파일·업무·자료의 소유권을 자동 변경하거나 넓히지 않는다.
- 파트너 권한·인증·서버 저장 revision/CAS와 DB/R2 스키마·보관 정책을 변경하지 않았다.
- 기존 진행이나 운영 데이터를 일괄 수정하지 않았다.

- 타입검사·전체 lint·프로덕션 빌드 통과
- `git diff --check` 통과

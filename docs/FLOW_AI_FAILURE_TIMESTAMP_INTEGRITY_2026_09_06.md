# 상담 FLOW AI 실패 관측시각 무결성 경계

기준일: 2026-09-06

## 문제·적용

공급자 실패 증거에 요청 신원과 HTTP 상태는 남았지만 실제 응답을 관측한 시각은 보존되지 않았다. 이 상태에서는 같은 작업의 반복 실패 순서를 감사 기록만으로 추정해야 하고, 직접 저장된 증거가 작업 실행 전이나 FLOW 수정 후의 값인지 판별할 수 없었다. 이제 Anthropic HTTP 4xx·5xx 응답을 받은 즉시 UTC 관측시각을 기록하고 현재 실패와 재시도 이력에 그대로 보존한다.

## 저장·검증 경계

- 관측시각은 기존 FLOW UTC timestamp 경계를 통과해야 하며 공급자 응답이 없는 로컬·네트워크 실패에는 만들지 않는다.
- 현재 실패 관측시각은 작업 시작시각 이상, 실패 저장시각 이하만 허용한다.
- 과거 실패 이력은 작업 생성시각 이상, FLOW 최종 수정시각 이하이며 배열 순서대로 시각이 감소하지 않아야 한다.
- 저장 전 전체 payload 검증과 D1 대시보드 축소 검증이 같은 시간 관계를 실패 폐쇄한다.
- Anthropic 오류 응답 본문은 저장하지 않고 상태·요청 ID·관측시각만 제한된 증거로 보존한다. 오류 상태와 요청 ID의 의미는 [Anthropic 공식 오류 안내](https://docs.anthropic.com/en/api/errors)를 기준으로 한다.

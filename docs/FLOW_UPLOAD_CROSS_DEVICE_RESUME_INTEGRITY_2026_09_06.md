# 상담 FLOW 교차 탭·기기 첨부 재시도 무결성

기준일: 2026-09-06

## 확인한 문제

상담 FLOW 첨부 저장이 불확실하게 끝나면 D1의 미완료 예약과 R2 키는 남아 정확한 재시도를 받을 수 있었다. 같은 탭의 새로고침은 임시 요청 ID를 이어 썼지만, 탭을 닫거나 다른 기기에서 다시 열면 새 요청 ID가 생성돼 기존 예약을 찾지 못했다. 사용자가 같은 명령과 같은 파일을 보유해도 새 비공개 파일 키를 만들 수 있는 공백이었다.

## 보완

- 서버가 먼저 같은 상담, 같은 인증 행위자, 같은 명령·첨부 SHA-256 지문인 `pending` 예약을 찾는다.
- 예약의 파일·음성 슬롯 수, 파일명, 고정 MIME, 크기, 용도와 신청자료 검토 출처가 현재 재시도와 모두 일치할 때만 기존 파일 ID와 R2 키를 재사용한다.
- 같은 요청 ID에 다른 지문이 있거나 슬롯·메타데이터가 달라지면 기존처럼 409로 중단한다.
- 부분 고유 인덱스가 상담·행위자·지문·슬롯마다 미완료 예약을 하나만 허용한다. 다른 요청 ID의 동일 첨부가 동시에 들어와도 하나의 예약으로 수렴한다.
- 별도 완료 증빙 원장은 실제 성공한 새 요청 ID를 파일 ID에 결속한다. D1 트리거는 해당 FLOW에 요청 ID와 명령 영수증이 있고 영수증의 행위자·지문이 예약과 정확히 일치하는지 확인한다.
- 완료 증빙은 수정·삭제할 수 없고, 예약은 이 증빙과 기존 FLOW 파일·소유권·메타데이터·R2 ETag 원장이 함께 확인된 경우에만 `ready`로 전이한다.

## 개인정보·운영 경계

- 브라우저 간 공유를 위해 원문, 파일 바이트, 인증정보를 새로 저장하지 않는다. 서버가 이미 보유한 SHA-256 지문과 안전한 파일 메타데이터만 사용한다.
- 다른 상담이나 다른 계정의 예약은 지문이 같아도 재사용하지 않는다.
- 요청 ID, 행위자 키, 지문, R2 저장 키와 완료 증빙은 관리자 인벤토리·파트너 응답에 노출하지 않는다.
- `pending` 예약을 자동 연결·삭제·만료하지 않는다. 내용이 달라졌거나 여러 예약이 모순되면 추정하지 않고 중단한다.
- 운영 D1/R2와 실제 고객 파일은 읽거나 변경하지 않았다.

## 회귀 검증

- 실패 뒤 새 요청 ID로 같은 파일을 다시 보내도 기존 파일 ID와 R2 키를 재사용하는지 확인했다.
- 서로 다른 요청 ID의 동일 첨부 동시 요청은 하나의 예약·파일·완료 증빙만 남기고 한 요청만 성공하는지 확인했다.
- 성공한 새 요청 ID가 FLOW 명령 목록·명령 영수증·완료 증빙에 동일하게 남는지 확인했다.
- 완료 증빙 변조·삭제와 증빙 없는 `ready` 전이를 D1이 거절하는지 확인했다.
- 마이그레이션을 기존 상태 위에 두 번 적용해도 상태를 교체하거나 실패하지 않는지 실제 Worker SQLite에서 확인했다.
- Node 711/711, 격리 workerd+D1+R2 521/521, 타입검사, 전체 lint, 변경 파일 포맷과 프로덕션 빌드를 통과했다.
- 로컬 Worker의 `/`, `/account`, `/account/setup`은 200, 비로그인 `/api/state`, `/api/admin/file-inventory`, `/api/consulting-flow/test-case`는 401과 `private`, `no-store` 경계를 반환했다.
- 격리 검증의 운영 쓰기, 메일, 유료 AI, 외부 요청은 모두 0건이다.

## 배포 경계

기능 커밋은 `7ef10a7079d7d09d47530caae2fc3ddb42ca96a4`이다. GitHub `main`과 Sites 소스에 반영했고 Sites 버전 256 (`appgprj_6a92514801988191b79eb9bd314e3fcd~appgver_83d3269982d08191a08b1fe299a43cfe`)으로 저장했다.

로컬 배포 아카이브는 1,686,533바이트, 240개 항목, SQL 95개이며 `.wrangler` 항목은 없다. SHA-256은 `637de24a982fcdf152d3b42a04c6d58fc77fb57dc0b3ccb083e6be219c960595`이다. Sites 수신 아카이브는 4,720,640바이트, 222개 파일이며 내용 해시는 `sha256:1b294634c2b4f8821d4a042651f8148b92a05318c8668ad6415d83ac252d7cce`이다.

현재 공개 운영본은 버전 107이다. 버전 108–255는 버전 256으로 대체하며, Sites 안전 게이트에 따른 정확한 `버전 256 운영 배포 승인` 전에는 공개 배포하지 않는다.

# Step 0 실행 직전 원본·동의 재검증

2026-09-01. 사용자의 별도 `다음 진행` 요청에 따라 AI 진단의 가상기업 Step 0 실행 경계를 점검했다. 완료된 자동 점검 3항목은 재개하지 않았으며 실제 고객 자료와 외부 AI를 사용하지 않았다.

## 재현과 수정

기존 서버는 저장된 A 판정과 일부 동의 값만 확인한 뒤 외부 AI 요청을 시작했다. 판정 뒤 자료가 삭제되거나 다른 반복 진행에 연결된 파일 ID가 카드에 남아 있어도 실제 D1 메타데이터와 R2 원본을 실행 직전에 다시 확인하지 않았다. 화면 판정에는 포함된 녹취 활용 동의도 서버 검사에서 빠져 있었다.

- 요청한 진행 ID와 기업명이 현재 진행 및 사전판정에 각각 하나로 일치하는지 다시 확인한다.
- A 판정, 기업 식별정보, 상담 근거, 민감정보 마스킹, 개인정보·제3자 AI·녹취 활용 동의를 모두 서버에서 다시 확인한다.
- 현재 진행과 담당 계정에 정확히 연결된 `제출완료`·`검토완료` 자료만 사용한다.
- 사업자등록증과 크레탑 또는 재무제표의 D1 메타데이터, 자료 종류, 진행·담당 연결, 삭제 상태를 확인한다.
- 외부 요청 직전에 R2 원본의 존재와 저장 크기 일치까지 확인한다. 하나라도 맞지 않으면 외부 요청 전에 차단한다.
- 클라이언트의 파일 ID나 과거 A 판정을 실제 저장 근거로 신뢰하지 않는다.

외부 AI 제공자·모델·비용 정책, 파일 보관·삭제 정책, DB/R2 구조와 마이그레이션은 변경하지 않았다.

## 가상 회귀 검증

격리된 가상 진행과 파일로 서버 API를 실행했다. 메타데이터 없는 완료 카드, 다른 반복 진행에 연결된 재무자료, R2에서 사라진 원본, 녹취 활용 동의 철회는 모두 HTTP 403으로 끝났고 모의 외부 호출 횟수는 0회였다. 정확한 진행·담당 계정에 연결된 두 필수 원본과 모든 동의가 있을 때만 모의 호출 1회와 Step 0 저장이 이뤄졌다.

- 전체 Node 검사 202개, 타입검사, lint, 빌드가 통과했다.
- 격리 workerd/D1/R2 검사 110개가 통과했고 실제 외부 요청·유료 AI·운영 쓰기는 0건이었다.
- 검사·빌드 로그는 `outputs/validation/step-zero-preflight-tests.log`, `step-zero-preflight-worker.log`, `step-zero-preflight-build.log`에 남겼다.
- 사용자 지침에 따라 브라우저 클릭 시험, 실제 파일 조회·등록, 외부 AI 호출은 수행하지 않았다.
- 운영 반영 상태는 `outputs/release/step-zero-preflight-deployment.json`에 기록한다. 기존 공개 사이트, D1/R2 연결, 추가형 마이그레이션 8개를 유지한다.

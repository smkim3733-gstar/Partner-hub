# 상담 FLOW AI 실패 이력 무결성 경계

기준일: 2026-09-06

## 문제·적용

공급자 실패 증거를 현재 실패 작업에 저장해도 대표가 비용을 확인하고 재시도하면 작업 상태를 `queued`로 되돌리는 과정에서 증거가 제거됐다. 여러 번 실패하면 최근 값으로 덮어써 이전 요청 추적도 사라질 수 있었다. 이제 재시도 직전에 현재 실패 증거를 순서가 보존된 이력으로 이동하고, 이후 실패·성공 상태와 무관하게 같은 작업에 유지한다.

## 저장·검증 경계

- 실패 이력은 현재 실패 증거와 같은 exact shape·문자열·HTTP 상태 경계를 각 항목에 적용한다.
- 이력은 1–20건만 허용한다. 20건이 찬 작업은 새 유료 요청 전에 재시도를 거절해 과거 증거를 버리거나 무제한 payload를 만들지 않는다.
- 공급자 응답이 없는 로컬 설정·권한·네트워크 실패는 거짓 공급자 이력을 만들지 않는다.
- 상세 조회와 민감정보 축소 대시보드는 중첩 배열의 예상 밖 키·손상 값·한도 초과를 모두 실패 폐쇄한다.
- 파트너 응답은 이력 각 항목의 허용 키만 다시 선택해 미래 내부 필드가 자동 노출되지 않게 한다.

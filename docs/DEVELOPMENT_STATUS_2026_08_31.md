# 개발 현황 — 2026-08-31

## 포함한 구현

기존 파트너 허브의 전체 코드, 35개 선행 개발 커밋, 최신 이메일·비밀번호 인증 개발본, 기획·입출력 명세·검증 문서를 함께 보관한다. 실제 고객 자료와 운영 DB는 보관 범위가 아니다.

### 계정

가입 항목은 이름, 핸드폰번호, 소속, 이메일 아이디, 사이트 전용 비밀번호다. 신규 가입은 승인대기로 등록하고 대표가 네 가지 파트너 유형 중 하나를 지정해 승인한다. 이메일은 메일 서비스 계정의 ID가 아니라 전체 이메일 주소를 사이트 로그인 ID로 사용하는 의미다. 메일 비밀번호를 수집하지 않는다.

기존에 등록된 이메일은 공개 가입으로 다시 가져갈 수 없다. 대표 본인 확인 후 30분 유효 일회용 설정 링크를 전달한다. 설정 완료 시 기존 사이트 비밀번호 세션을 무효화한다. 자동 발송은 없으며 관리자 및 기존 ChatGPT 로그인도 남아 있다.

### 업무

협업신청 → 근거자료 검토 → 1차 보고서 등록·공유 → 대표/파트너 각각 분석 완료 → 초회상담 예약 → 2차 보고서·3차 PPT 준비 → 동반 상담 → 녹취자료 등록·4차 심화분석 → 대표의 솔루션 확정 → 추가서류 요청·수령·확인 → 5차 견적·6차 계약서 준비 → 계약상담·서명본 등록 → 계약금 확인 → 수행·사후관리 흐름이다.

상담·서류요청은 필요한 횟수만큼 반복한다. 서명과 입금 확인은 별개이고, 상담 횟수나 자료 제출만으로 계약·입금·성공을 확정하지 않는다. 공유 일정은 다른 기업의 상세정보를 가린다. 신규 상담 FLOW는 담당 계정 ID에 연결된다.

### 자료와 AI

초기 신청 시 기업자료와 전화통화 녹취자료를 함께 등록한다. 상담 후에는 DOCX/TXT 또는 검토한 전사 본문을 중심으로 입력하고, 음성은 보조 파일로 보관한다. 전사문·식별정보·기업·상담일·금액을 확인해야 하며 자동 OCR·마스킹이나 원음 자동 전사를 완료된 기능으로 표시하지 않는다.

AI 1차/4차는 기업별 외부 처리·마스킹·비용 확인 후 서버 API로 요청한다. 키 존재 확인과 실제 키 인증/잔액/모델 이용 가능 확인은 다르다. 2차/3차/5차/6차는 대표가 준비한 실제 문서 등록 방식이다. 최종 검토와 고객 전달은 대표 판단을 유지한다.

- Google Calendar 양방향 연동, 음성 전사 서비스, 카카오톡·이메일 발송, 전자서명, 은행 입금 자동조회는 미연결이다.
- 이메일·비밀번호 개발본의 공개 사이트 배포와 실제 파트너 로그인 파일럿은 GitHub 업로드와 별개다.

- UI 공통 컴포넌트의 기존 lint 오류는 별도 정비 항목이다.

# AI 진단 준비·Step 0 응답 검증 안전성

## 문제

AI 진단 화면은 연동 준비상태와 Step 0 조회·생성 응답을 타입 단언으로 적용했다. 손상된 준비상태가 생성 가능으로 표시되거나, 다른 진행·기업·요청의 실행 결과와 잘못된 보고서 구조가 현재 화면에 표시될 수 있었다.

## 변경

- AI 준비상태의 제공자·연결방식·지침·API 키·모델·원본 저장소·다음 행동 필드를 검증한다.
- `generationEnabled`는 API 키·모델·원본 저장소 준비값의 논리 결과와 일치해야 한다.
- Step 0 결과는 현재 진행 ID와, 생성 응답에서는 기업명·요청 ID까지 정확히 일치해야 한다.
- 고정 단계·검토상태·지침 버전·모델·생성시각·토큰 수와 전체 결과 배열·솔루션 구조를 검증한다.
- 명시적인 결과 없음은 조회에서만 허용하고 생성 성공에서는 차단한다.
- 검증된 공개 필드만 반환하며 비-JSON·손상된 응답과 HTTP 오류는 안전한 안내로 처리한다.

## 유지한 운영 경계

- AI 준비상태와 Step 0 서버 계약·권한·동의·사전점검·실행 잠금·결과 저장을 변경하지 않았다.
- Anthropic API 키·모델·비용 설정을 변경하지 않았고 외부 AI 호출을 실행하지 않았다.
- 기존 AI 결과·원본·운영 데이터·DB/R2 스키마·보관 정책을 변경하지 않았다.
- GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다.

## 검증

- 자동 테스트: 367개 통과
- 격리 workerd/D1/R2 스모크: 129개 통과
- TypeScript `--noEmit`, 전체 lint, 프로덕션 빌드 통과
- 기존 개발 서버 `/` 응답: HTTP 200
- 검증 중 운영 쓰기·메일 발송·유료 AI·외부 요청: 각 0건

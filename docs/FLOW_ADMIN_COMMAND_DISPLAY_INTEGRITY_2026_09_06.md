# 상담 FLOW 관리자 명령 표시 무결성

기준일: 2026-09-06

## 문제·적용

새 관리자 명령이 `admin:primary` 신원 키를 사용해도 영수증과 감사기록의 행위자 표시를 함께 다른 이름으로 바꾸면 기존 의미 결속을 통과할 수 있었다. 이제 관리자 명령 생성은 공용 대표 표시값을 사용하고 애플리케이션과 추가형 `0057` D1 트리거가 새 관리자 명령의 행위자 표시를 `김성민 대표` 역할에 결속한다.

## 감사·보존 경계

- 새 `admin:` 명령의 영수증 행위자 표시는 정확히 `김성민 대표`여야 한다.
- 같은 명령 ID 감사기록은 기존 의미 결속에 따라 영수증과 같은 표시를 가져야 한다.
- 앱 저장 경로와 직접 D1 삽입·갱신 경로에 같은 조건을 적용한다.
- 기존 관리자 명령과 영수증은 후속 revision에서 바꾸지 않으며 레거시 표시를 자동 수정하지 않는다.
- 회원 명령은 기존 담당 계정 ID·담당자명 결속을 유지한다.

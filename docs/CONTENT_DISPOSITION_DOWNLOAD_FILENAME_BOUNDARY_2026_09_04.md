# 다운로드 파일명 Content-Disposition 보안 경계

## 목적

기업 원본, 상담 FLOW 첨부, 보고서 Markdown 다운로드가 저장된 파일명이나 문서 제목을 HTTP 헤더에 직접 조립하지 않도록 공용 경계를 적용한다.

## 적용 범위

- 세 다운로드 경로가 공용 `attachmentContentDisposition` 함수만 사용한다.
- 파일명은 NFC로 정규화하고 제어문자, 경로 구분자, 깨진 유니코드 단위를 `_`로 치환한다.
- 최대 180개 유니코드 코드 포인트만 사용하고 빈 결과는 `download`로 대체한다.
- UTF-8 `filename*` 값은 RFC 5987 형식으로 인코딩하며 작은따옴표·괄호·느낌표·별표도 퍼센트 인코딩한다.

## 유지한 경계

원본 파일 내용·MIME·저장 이름, 상담 FLOW 보고서 제목, 인증·담당 계정·권한 재확인, R2 키와 D1 스키마는 변경하지 않았다. 헤더에 표시할 다운로드 이름만 응답 직전에 안전하게 만든다.

## 재발 방지

정적 회귀검사는 다운로드 라우트가 공용 함수를 참조하는지 확인하고 `Content-Disposition` 템플릿 문자열을 라우트에서 직접 조립하지 못하게 한다. 한국어, 제어문자·경로 구분자, RFC 특수문자, 깨진 유니코드, 빈 이름을 별도 단위검사로 고정했다.

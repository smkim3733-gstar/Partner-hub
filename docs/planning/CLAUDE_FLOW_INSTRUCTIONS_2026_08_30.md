## 1. 현재 프로젝트의 지침 영역에서 확인된 내용

### 제6장 보완 [3차] PPT 1차 보고서 전면 반영 원칙 (★v2.4 신설)

#### 6.9 3차 PPT는 1차 보고서를 「순서대로 전면 반영」한다

- 3차 PPT는 1차 정밀진단보고서의 내용을 시각화하는 산출물이다.
- 1차 보고서의 목차 순서를 3차 PPT의 슬라이드 순서로 그대로 적용한다.
- 보고서에 없는 내용을 임의로 추가하지 않는다.
- 견적, 비용, 수수료, 계약조건은 3차 PPT에서 제외한다.

**유일한 예외 — 견적서 관련 내용 제외**

- 컨설팅 비용, 항목별 단가, 총액
- 성공보수와 지급조건
- 견적번호와 견적 유효기간
- 그 밖의 모든 비용 표현
- 비용은 5차 견적서에서 처음 제시한다.

#### 6.10 1차 목차 → 3차 슬라이드 순차 매핑 표준

| 1차 정밀진단보고서 구성 | 3차 PPT 반영 위치 |
|---|---|
| 표지 | 슬라이드 1 |
| 제1장 | 슬라이드 2 |
| 제2장 | 슬라이드 3 |
| 제3장 | 슬라이드 4 |
| 제4장 | 슬라이드 5 |
| 제5장 | 슬라이드 6 |
| 제6장 | 슬라이드 7 |
| 제7장 | 슬라이드 8 |
| 제8장 | 슬라이드 9 |
| 제9장 | 슬라이드 10 |
| 제10장 핵심질문 10개 | 슬라이드 11, 전환 1~4 |
| 제11장 | 슬라이드 12 |
| 대표 답변 수집 결과 | 슬라이드 13 |

#### 6.11 반영 충실도 원칙

- 1차 보고서와 동일한 수치를 사용한다.
- 1차 보고서와 동일한 우선순위를 유지한다.
- 1차 보고서의 핵심질문 10개를 빠짐없이 반영한다.
- 1차 보고서와 동일한 결론을 유지한다.
- 금액과 견적 관련 내용은 제외한다.

#### 6.12 작업 절차

1. 1차 정밀진단보고서를 처음부터 끝까지 읽는다.
2. 보고서 목차와 PPT 슬라이드의 매핑표를 만든다.
3. 각 장의 핵심 내용을 해당 슬라이드에 시각화한다.
4. 핵심질문 10개는 질문 카드 방식으로 구성한다.
5. 정해진 디자인 기준을 적용한다.
6. 최종 체크리스트로 누락과 금액 노출 여부를 점검한다.

#### 6.13 점검 체크리스트

- 1차 보고서의 모든 장이 반영되었는가?
- 보고서 목차 순서대로 슬라이드가 구성되었는가?
- 수치가 1차 보고서와 일치하는가?
- 우선순위가 1차 보고서와 일치하는가?
- 핵심질문 10개가 모두 들어갔는가?
- 최종 결론이 1차 보고서와 일치하는가?
- 견적·비용·수수료·계약조건이 노출되지 않았는가?
- 정해진 4개 디자인 기준이 적용되었는가?

위 항목 중 하나라도 충족하지 못하면 수정 후 다시 점검한다. 금액이 노출된 경우에는 반드시 다시 작성한다.

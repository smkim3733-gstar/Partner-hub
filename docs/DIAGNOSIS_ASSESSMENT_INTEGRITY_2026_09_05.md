# 진단평가 기록 무결성 경계

기준일: 2026-09-05

## 확인한 문제

진단평가 배열은 일반 객체와 고유 ID만 확인했다. 필수 필드가 없거나 동의값이 문자열·숫자인 기록, 허용되지 않은 식별 상태, A/B/C 등급과 결정·처리상태가 모순된 기록도 관리자 일반 저장을 통과했다. 존재하지 않는 진행 ID나 다른 기업명에 연결된 평가도 저장할 수 있어 화면 재판정·검토대기 갱신 대상을 확정할 수 없었다.

## 적용한 경계

- 평가 ID·진행 ID·기업명·갱신 표시는 공백 없는 문자열이어야 한다.
- 기업 식별상태는 `일치`, `확인필요`, `불일치`만 허용한다.
- 상담 근거·민감정보 마스킹·개인정보 처리·제3자 AI 처리·녹취 활용 동의는 정확한 boolean이어야 한다.
- 등급은 A/B/C, 결정과 처리상태는 화면이 사용하는 허용값만 받는다.
- A는 `1차 초안 생성 가능`과 `사전점검 완료` 또는 `대표 검토 대기`, B는 `Step 0·보완요청`과 `보완자료 대기`, C는 `AI 처리 중단`과 `처리 중단` 조합만 허용한다.
- 각 평가는 같은 `caseId`와 기업명을 가진 진행 하나에 정확히 연결되어야 한다.
- 공용 순수 검증기를 서버 저장·조회와 클라이언트 최초 상태 응답에 함께 적용한다.
- 조작 저장은 403, 이미 저장된 손상 상태는 파트너 조회 403, 관리자 조회와 일반 저장 503으로 격리한다.
- 운영 데이터 자동 수정, D1/R2 조회·변경, 외부 AI 전송은 수행하지 않았다.

## 검증

- 수정 전 재현: 문자열 동의, 모순된 등급·결정, 존재하지 않는 진행 연결이 관리자 저장 200 또는 파트너 조회 200으로 통과했다.
- 수정 후: 조작 저장 403, 손상 상태 파트너 조회 403, 관리자 조회·일반 저장 503.
- Node 자동 테스트 519/519 통과.
- 격리 workerd+D1+R2 검사 262/262 통과.
- 타입검사, 전체 lint, 프로덕션 빌드 통과.
- 로컬 프로덕션 `/`, `/account`, `/account/setup` HTTP 200과 화면 보안 헤더 확인.
- 실제 운영 쓰기, 메일 발송, 유료 AI 요청, 외부 요청 0건.

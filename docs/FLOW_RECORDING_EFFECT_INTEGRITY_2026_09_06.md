# 상담 FLOW 녹취 등록 효과 무결성

기준일: 2026-09-06

## 보완 내용

`save_recording` 명령의 상태 변경을 새 녹취 한 건, 관련 첨부와 4차 AI 작업 한 건에 정확히 결속했다.

- 완료된 기존 상담에 명령 ID로 결속된 새 녹취 한 건만 추가한다.
- 녹취 생성·활용동의 시각을 FLOW 갱신시각에 맞추고, 전사문이 있으면 같은 시각의 검토 기록과 검토자를 요구한다.
- 전사문·주 첨부·보조 음성 조합에 따라 새 파일 0–2건만 허용하고, 녹취 참조 순서·용도·생성시각과 문서·음성 확장자 역할을 결속한다.
- 명령 ID로 결속된 새 4차 작업 한 건만 추가하고 최신 1차 보고서·새 녹취를 원본으로 사용한다.
- 전사문 유무와 AI 자동생성 정책에 따라 새 작업의 `queued`/`blocked` 상태와 고정 사유를 정확히 결정한다.
- 기존 녹취·파일·작업의 값과 순서를 모두 보존하고, 미참조 파일과 다른 작업 변조를 거절한다.
- 애플리케이션 커밋 검사와 추가형 `0074` D1 트리거가 같은 효과를 독립 강제한다.

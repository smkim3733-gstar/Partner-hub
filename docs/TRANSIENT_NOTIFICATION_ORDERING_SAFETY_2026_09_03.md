# 연속 사이트 알림 표시 순서 안전성

## 문제

사이트 알림은 표시할 때마다 2.6초 뒤 숨김 타이머를 새로 만들었다. 짧은 간격으로 알림이 두 번 발생하면 첫 알림의 오래된 타이머가 뒤에 표시된 최신 알림을 예정 시각보다 일찍 숨길 수 있었다.

## 변경

- 알림마다 증가하는 순서를 부여한다.
- 가장 최근 알림이 만든 숨김 콜백만 알림을 닫을 수 있다.
- 이전 알림의 늦은 콜백은 현재 메시지를 바꾸지 않는다.
- 화면을 닫으면 대기 중인 알림 콜백을 모두 무효화한다.

## 유지한 운영 경계

- 알림 문구·표시시간·접근성 속성·업무 판정과 저장 동작을 변경하지 않았다.
- 운영 데이터·DB/R2 스키마·인증·권한·보관 정책, 외부 발송·유료 AI 설정을 변경하지 않았다.
- GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다.

## 검증

- 자동 테스트: 348개 통과
- 격리 workerd/D1/R2 스모크: 129개 통과
- TypeScript `--noEmit`, 전체 lint, 프로덕션 빌드 통과
- 기존 개발 서버 `/` 응답: HTTP 200
- 검증 중 운영 쓰기·메일 발송·유료 AI·외부 요청: 각 0건

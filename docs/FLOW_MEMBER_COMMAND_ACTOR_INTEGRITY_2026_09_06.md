# 상담 FLOW 회원 명령 행위자 결속 무결성

기준일: 2026-09-06

## 문제·적용

새 명령 영수증의 행위자 키가 `member:` 형식이어도 해당 상담 FLOW의 실제 담당 계정이 아닌 다른 회원 ID를 넣을 수 있었고, 영수증과 감사기록의 담당자 표시를 함께 바꾸면 형식 검사를 통과할 수 있었다. 이제 애플리케이션과 추가형 `0055` D1 트리거가 회원 명령의 행위자 키를 정확히 `member:{담당 계정 ID}`에 결속하고 영수증·감사기록의 행위자 표시를 FLOW 담당자명과 일치시킨다.

## 감사·보존 경계

- `member:` 명령은 현재 FLOW의 불변 `partnerId`와 정확히 같은 계정만 허용한다.
- 회원 명령 영수증과 같은 ID 감사기록의 행위자 표시는 FLOW의 `partnerName`과 일치해야 한다.
- 앱 저장 경로와 직접 D1 삽입·갱신 경로에 같은 조건을 적용한다.
- 기존 명령과 영수증은 후속 revision에서 변경하지 않으며 레거시 읽기 호환을 유지한다.
- `admin:` 명령의 관리자 안정 ID 결속은 별도 후속 감사 대상으로 남긴다.

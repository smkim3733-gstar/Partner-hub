# 상담 FLOW 신청자료 원본 읽기·해시 경쟁 무결성

기준일: 2026-09-07

## 확인한 경계

대표가 기업자료 원본을 신청자료로 미리 보거나 상담 FLOW 근거자료로 가져올 때 R2 본문 읽기, 문서 해석과 SHA-256 계산이 수행된다. 이 비동기 작업 중 사건이 삭제되거나 담당 계정이 바뀌고, 읽던 원본 객체가 교체되더라도 오래된 내용이 반환되거나 새 FLOW 업로드 예약·복사 객체가 만들어져서는 안 된다.

## 발견·수정

- 신청자료 미리보기는 최초 권한만 확인한 뒤 R2 읽기와 해시 결과를 바로 반환했다. 읽는 동안 사건이 삭제되면 이미 가져온 비공개 원문을 200으로 반환할 수 있었다.
- 신청자료 가져오기는 원본 읽기와 해시가 끝난 직후 FLOW 명령을 검증하고 업로드 예약을 만들었다. 읽는 동안 담당 계정이 바뀌면 다음 예약 후 검사에서 거절되지만 접근 상실 뒤 새 `pending` 예약이 먼저 생길 수 있었다.
- 원본 로더는 R2 객체의 최초 ETag·MIME·크기만 검사했다. 본문을 읽는 동안 현재 R2 객체가 교체되어도 읽기 시작 시점 객체의 해시만으로 처리를 이어갈 수 있었다.
- R2 읽기와 해시 뒤 기업자료 행·표시 가능 상태·기업·사건·담당 계정·전체 원본 사실·불변 무결성 원장을 다시 읽는다. 현재 R2 `head`와 읽기 시작 객체가 모두 최신 ETag·MIME·크기에 맞아야 결과를 사용한다.
- 미리보기 응답 직전에는 현재 사건·계정·담당 정보를 다시 확인한다. 사건 삭제 경쟁은 404로 끝나고 비공개 원문과 해시를 반환하지 않으며 FLOW도 만들지 않는다.
- 가져오기 원본 준비 직후와 FLOW 예약 전에 같은 접근·생명주기를 다시 확인한다. 담당 재배정 경쟁은 403으로 끝나며 새 업로드 예약과 목적지 R2 객체를 만들지 않는다.
- 읽기 시작 뒤 같은 크기 원본 교체 경쟁은 최신 R2 ETag 불일치를 409로 반환한다. 새 FLOW 예약·복사 객체·명령 영수증·파일 원장·완료 원장은 모두 0건이다.

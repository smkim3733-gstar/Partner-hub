# 상담 FLOW 파일·음성 슬롯 결속 무결성

기준일: 2026-09-06

## 확인한 공백

상담 녹취 등록은 전사문 파일과 보조 음성을 한 요청에서 함께 저장할 수 있다. 애플리케이션은 두 파일의 역할을 구분했지만, 완료 원장의 D1 트리거는 예약의 행위자와 SHA-256 요청 지문만 확인했다. 따라서 애플리케이션을 우회한 직접 D1 입력에서는 `audio` 예약이 실제 녹취의 `audioFileId`가 아닌 다른 파일을 가리켜도 완료 증명 생성 단계까지 도달할 수 있었다.

## 적용한 경계

- `audio` 슬롯은 `recording` 목적의 MP3·M4A·WAV만 예약할 수 있다.
- 파일과 음성을 함께 예약할 때 기본 `file` 슬롯은 Word 또는 TXT 전사문이어야 한다.
- 완료 원장은 실제 성공 명령으로 생성된 녹취 ID와 `audioFileId`를 확인한다.
- 같은 예약 묶음에 `file`과 `audio`가 모두 있으면 녹취의 `fileId`와 `audioFileId`가 두 예약의 파일 ID에 각각 정확히 일치해야 한다.
- 다른 탭이나 기기에서 새 명령 ID로 재시도해도 원래 두 예약의 파일 ID와 R2 키를 함께 재사용하고, 두 완료 행은 실제 성공 명령 ID 하나에 결속한다.
- 슬롯이 바뀌거나 파일 역할이 맞지 않으면 애플리케이션과 D1 모두 실패 폐쇄한다.

추가형 마이그레이션 `0095_consulting_flow_upload_slot_binding.sql`은 기존 완료 트리거를 새 슬롯 결속 트리거로 교체한다. 마이그레이션은 격리된 네이티브 D1에서 두 번 적용해도 같은 상태를 유지한다.

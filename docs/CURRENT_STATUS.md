# 현재 구현과 다음 확인 순서

2026-09-03 기준. 이 문서는 현재 코드의 기능과 운영 경계를 정리한다. 날짜별 검증 문서는 당시 기록이며, 과거의 배포 대기 문구나 테스트 수를 현재 상태로 해석하지 않는다. 실제 반영 결과는 Sites 배포 이력과 로컬 `outputs/release/` 기록을 기준으로 확인한다.

## 현재 사용할 수 있는 기능

- 사이트 전용 이메일·비밀번호 가입, 대표 승인·직접 등록·정지, 일회용 비밀번호 설정. ChatGPT 로그인 경로도 유지한다.
- 대표의 파트너 직접등록과 승인대기 검토는 유형을 자동 선택하지 않는다. 허용된 네 유형 중 하나를 직접 골라야 등록·승인하며, 기존 활성·정지 계정 편집은 저장된 유형을 유지한다.
- 계정·권한 설정의 이메일·파트너 유형·로그인 상태·개별 권한은 저장 전 초안에만 머문다. 저장하면 함께 반영되고 취소하거나 닫으면 모두 폐기된다.
- 담당 계정 ID 기준 진행·업무·원본 접근. 동명이인만으로 타인 자료 접근을 허용하지 않으며 모호한 레거시 자료는 자동 이관하지 않는다.
- 대표가 진행 담당 계정을 선택하면 현재·변경 후 계정을 별도 확인한 뒤 저장한다. 취소하면 바뀌지 않으며, 기존 원본파일·업무·자료 담당은 자동 이전하지 않는다.
- 수동 진행단계와 진행 중단·재개는 현재·변경 후 상태와 영향을 확인한 뒤 저장한다. 취소하면 바뀌지 않으며 저장 직전 최신 단계·생명주기 상태를 다시 검사한다.
- 현재 계정이 조회할 수 있는 진행 안에서 기업명·전체 신청번호·표시 번호로 검색하고 해당 진행 화면으로 이동한다. 같은 기업의 반복 신청이나 여러 부분검색 결과는 신청번호 입력을 요구한다.
- 대표는 전체 진행현황의 현재 필터 결과를 Excel 호환 CSV로 내려받을 수 있다. 가상 예시와 계정 이메일·내부 ID·신청 상세·원본 내용은 제외한다.
- 상단과 데스크톱·모바일 메뉴는 현재 계정의 오늘 마감·기한 지연 운영 업무만 사이트 알림 숫자로 표시한다. 가상 예시와 완료 업무는 제외하며, 알림이 있으면 같은 기준의 `확인 필요` 목록을 바로 연다.
- 새 업무 등록은 빈 업무명·업무유형·마감일·마감 구분에서 시작한다. 지원 요청 유형도 자동 선택하지 않으며 업무유형과 조건부 지원분류를 공용 허용 목록으로 검증한다. 기업 연계 업무만 기업명을 요구하고 지원 요청·내부 업무는 각각 고정 범위를 사용하며, 성공 뒤 이전 입력을 남기지 않는다.
- 업무 완료·재개와 지원요청 처리 시작은 현재·변경 후 상태와 알림·처리지표 영향을 확인한 뒤 저장한다. 취소하면 기존 상태를 유지하며 저장 직전 업무 내용·담당·마감·지원 주기·현재 역할을 다시 검사한다.
- 기업자료 등록은 빈 기업명·자료명·자료종류에서 시작하고 화면·서버가 같은 필수값과 길이 제한을 검증한다. 자료종류를 파일명으로 확정하지 않으며 사용자가 직접 선택해야 한다. 기업·담당·종류·자료명·파일 변경 시 제출 동의를 다시 받으며, 성공 또는 닫기 뒤 이전 메타정보를 남기지 않는다.
- 기업자료 상태 변경은 현재·변경 후 상태와 영향을 확인한 뒤 저장한다. 취소하면 기존 상태를 유지하며 저장 직전 자료 ID·최신 상태·보안 원본 연결을 다시 검사한다.
- 새 협업신청은 요청서비스를 자동 선택하지 않고 사용자가 허용 목록에서 직접 골라야 한다. 대표 대리접수의 신청자 유형도 빈 상태에서 직접 선택하며, 공유 계정을 고르면 현재 활성 계정의 등록 유형으로 고정한다. 신청자명·유형·기업명·서비스를 단계 이동과 제출 직전에 공통 검증하며 신청자 유형 변경 뒤 자료·녹취 동의를 다시 받는다. 기업 기본자료의 파일명 기반 종류는 제안으로만 표시하고 파일별 확인 전에는 제출하지 않는다.
- 새 상담 등록은 빈 제목에서 시작하고 상담방식·상태·후속조치·일정 추가를 자동 선택하지 않는다. 제목·일시와 공용 허용값을 저장 직전에 검증하며 상태가 바뀌면 호환되지 않는 일정·후속조치를 제거한다. 허브 일정 추가 시 공개범위를 직접 골라야 하며 일정 미추가는 내부 전용으로 정규화한다.
- 새 서류요청은 빈 목록에서 시작하고 추천 서류도 사용자가 직접 추가해야 한다. 서류명과 기한을 저장 직전에 검증하며 실제 저장되지 않던 필수·선택 표시는 제공하지 않는다. 제출기한은 한국시간 기준 과거·오늘·미래로 분류해 후속 업무 알림 상태와 우선순위를 함께 정한다.
- 누락된 요청서류 제출기한은 대상 자료·연결 업무·알림 영향을 확인한 뒤 일괄 저장한다. 저장 직전 권한·진행 연결·자료와 업무 상태·한국 날짜 기준을 다시 검사하며, 다른 반복 진행이나 기존 날짜 기록은 바꾸지 않는다.
- 기업별 반복 협업신청, 신청 항목 저장, 서버 저장 확인 후 완료 안내, 같은 신청 재시도.
- 계정별 신청 텍스트 임시저장·복구. 첨부와 제출 동의는 자동 복구하지 않는다.
- 원본 업로드 응답 유실 시 재사용, 부분 실패 보존, 대표 전용 보관 목록·존재 검사.
- 오래 걸린 파일 요청의 계정·권한 재확인, 메타데이터 저장·삭제 결정 시 운영 상태 일치 확인. 중단된 업로드 원본은 보존하며, 다운로드 응답 직전 정지·삭제 상태를 다시 확인한다.
- 기존 신청·기업·담당 계정이 일치하는 원본만 대표 확인으로 회수. 원본 파일은 유지하고 자료 목록과 확인 이력을 함께 저장한다.
- 일반 저장에서 회수 연결·확인 사유·확인자·시각·이력의 위조·수정·누락·중복을 차단한다. 자료 카드에서 회수 사유와 한국시간 기준 시각을 읽을 수 있다. 검토 상태 변경은 허용한다.
- 상담 FLOW, 반복 상담·서류 요청, 보고서 등록, 대표/파트너 확인, 견적·계약·서명·입금의 개별 확인.
- 상담 FLOW의 추가서류 필요 여부·대표 검토 결과·서류 전달 경로·필수 여부는 자동 선택하지 않는다. 신규 사후관리 담당자도 직접 입력하며 기존 기록 수정은 저장값을 다시 표시한다.
- 상담 FLOW 예약은 가능한 단계에서만 입력할 수 있다. 초회상담은 동반 참석 규칙을 읽기 전용으로 표시하고, 이후 추가·계약상담의 종류와 참석 방식은 자동 선택 없이 직접 골라야 한다.
- 상담 FLOW 저장 직전 권한·명단 재확인, 계정·명령 내용·첨부 해시가 일치하는 동일 요청 재시도. 외부 AI 요청 직전에도 호출 계정과 작업 승인 상태를 확인한다.
- 승인된 외부 처리·비용 확인을 거친 AI 1차/4차 초안 요청 경로. 보고서 최종 승인과 고객 전달은 대표 판단이다.
- 가상기업 Step 0 시험은 빈 설명에서 시작하고 20~8,000자·식별정보 부재·현재 입력 동의를 외부 호출 전에 검증한다. 입력 변경과 생성 성공 뒤에는 동의를 다시 받아야 한다.
- 가상 진단의 1차 초안 검토대기 등록은 최신 A 판정과 저장 영향을 확인한 뒤 적용한다. 저장 직전 관리자 역할·가상 진단/진행·근거/동의를 다시 검사하며, 고정 가상 파생 업무로 만들어 운영 알림·지표에서 제외한다.
- 새 저장소의 대표 선택형 기준선 초기화, 가상 예시를 제외한 대표 운영 지표, 관리자 전용 저장 용량·잠정 경보 표시.
- 저장 경로 3곳의 개인정보 없는 일별 충돌 집계와 대표 전용 최근 7일 지표. 기존 409·입력 보존·수동 재시도 방식은 유지한다.
- 저장 충돌 뒤 24시간 동안 열린 화면 메모리에서만 전달하는 익명 단일사용 회수 영수증. DB에는 토큰 해시와 서버 경로·역할·충돌 종류·시각만 보관하고, 대표에게 경로별 관측 회수율과 최소 5건 이상인 거친 시간 구간만 표시한다.
- 비밀번호 설정 링크의 발급·활성 링크 교체·만료 후 재발급·설정 완료·관측된 만료 시도를 식별정보 없이 한국 날짜별로 합산하고, 대표 계정관리 화면에는 최근 7일 총계만 표시한다.
- 신규 협업신청의 서버 접수시각과 상담 FLOW의 초회상담 완료기록을 연결한 대표 전용 파일럿 지표. 레거시 상담은 측정 불가로 분리하고 유효 소요시간 5건 미만에는 구간을 숨긴다.
- 상담 FLOW·기업자료 업로드·대표 직접등록의 안전 재시도와 요청번호 충돌을 개인정보 없이 집계한 대표 전용 최근 7일 지표. 식별값 없는 업로드는 판별 범위 경고로 분리한다.
- 최신 1차 보고서의 대표·파트너 독립 확인 순서와 간격을 개인정보 없이 합산한 대표 전용 현재 상태 지표. 전체 승인 병목이나 실제 업무 인계를 뜻하지 않는다.
- 추가서류의 최신 수령·재검토 주기에서 대표 검토 완료시간과 현재 대기 연령을 개인정보 없이 합산한 대표 전용 현재 상태 지표. 기존 기록과 수령 역할은 추정하지 않는다.
- 기존 업무에 고정 지원 요청 유형과 서버 등록·대표 인지·완료 시각을 기록하고, 대표 완료와 요청자 자가종료를 분리한 대표 전용 현재 상태 지표. 요청자 소유권과 기존 보관 경계를 유지한다.
- 신규 협업신청의 서버 소유 생명주기와 대표의 명시적 진행 중단·재개. FLOW 확인 단계와 수동 보고 단계를 분리한 관리자 전용 단계별 중단 지표를 제공하며, 중단된 진행의 FLOW 쓰기는 재개 전까지 차단한다.

# 현재 구현과 다음 확인 순서

2026-09-01 기준. 이 문서는 현재 코드의 기능과 운영 경계를 정리한다. 날짜별 검증 문서는 당시 기록이며, 과거의 배포 대기 문구나 테스트 수를 현재 상태로 해석하지 않는다. 실제 반영 결과는 Sites 배포 이력과 로컬 `outputs/release/` 기록을 기준으로 확인한다.

## 현재 사용할 수 있는 기능

- 사이트 전용 이메일·비밀번호 가입, 대표 승인·직접 등록·정지, 일회용 비밀번호 설정. ChatGPT 로그인 경로도 유지한다.
- 담당 계정 ID 기준 진행·업무·원본 접근. 동명이인만으로 타인 자료 접근을 허용하지 않으며 모호한 레거시 자료는 자동 이관하지 않는다.
- 기업별 반복 협업신청, 신청 항목 저장, 서버 저장 확인 후 완료 안내, 같은 신청 재시도.
- 계정별 신청 텍스트 임시저장·복구. 첨부와 제출 동의는 자동 복구하지 않는다.
- 원본 업로드 응답 유실 시 재사용, 부분 실패 보존, 대표 전용 보관 목록·존재 검사.
- 오래 걸린 파일 요청의 계정·권한 재확인, 메타데이터 저장·삭제 결정 시 운영 상태 일치 확인. 중단된 업로드 원본은 보존하며, 다운로드 응답 직전 정지·삭제 상태를 다시 확인한다.
- 기존 신청·기업·담당 계정이 일치하는 원본만 대표 확인으로 회수. 원본 파일은 유지하고 자료 목록과 확인 이력을 함께 저장한다.
- 일반 저장에서 회수 연결·확인 사유·확인자·시각·이력의 위조·수정·누락·중복을 차단한다. 자료 카드에서 회수 사유와 한국시간 기준 시각을 읽을 수 있다. 검토 상태 변경은 허용한다.
- 상담 FLOW, 반복 상담·서류 요청, 보고서 등록, 대표/파트너 확인, 견적·계약·서명·입금의 개별 확인.
- 상담 FLOW 저장 직전 권한·명단 재확인, 계정·명령 내용·첨부 해시가 일치하는 동일 요청 재시도. 외부 AI 요청 직전에도 호출 계정과 작업 승인 상태를 확인한다.
- 승인된 외부 처리·비용 확인을 거친 AI 1차/4차 초안 요청 경로. 보고서 최종 승인과 고객 전달은 대표 판단이다.

## 검증과 배포 경계

이번 후속 변경은 자동 테스트 183개와 격리 workerd/D1/R2 검증 110개를 기준으로 확인한다. lint·타입검사·빌드 결과와 배포 상태는 [상담 FLOW 권한·중복 요청 점검](FLOW_PERMISSION_REVIEW_2026_09_01.md)에 구분해 남긴다. 기존 추가형 DB 마이그레이션 8개와 DB/R2 연결을 유지한다.

운영 고객 파일·명단을 개발용으로 읽거나 복사하지 않는다. 가상 데이터로 테스트하며 실제 계정 등록·메일 발송·유료 AI를 검증 수단으로 사용하지 않는다. 서비스 전체 침투시험, 실제 파트너의 로그인 쿠키 왕복과 전체 레거시 이관은 완료로 표시하지 않는다.

별도 승인에 따른 [로컬 가상 데이터 화면 점검](LOCAL_SCREEN_REVIEW_2026_09_01.md)으로 로그인·신청·첨부·회수·FLOW 초기 역할과 재시도를 확인했다. 파트너 홈의 고정 예시 목록·수치를 허용된 저장 데이터로 연결하고, FLOW의 비정상 응답을 한국어 재시도 안내로 보완했다. 키보드 전용 조작 및 전체 FLOW 단계의 브라우저 검증은 미완료로 구분한다. 기존 3항목 자동 점검은 재개하지 않는다. 후속 화면 수정의 반영 상태는 `outputs/release/ui-screen-deployment.json`을 기준으로 한다.

## 이어서 진행할 점검

이 목록은 기존 기능을 보호하는 점검이며 신규 외부 서비스 도입이나 실제 고객 업무를 승인하는 목록이 아니다. 한 항목씩 재현 가능한 코드·격리 검증을 수행하고, 필요한 수정이 있으면 검증 후 기존 사이트에 반영한다. 변경이 필요 없으면 그 근거를 기록한다.

1. [x] 원본 회수 완료·응답 유실·재시도 시 화면 저장 잠금과 최신 상태 반영 경로 점검. 응답 유실 뒤 잠금 유지·동일 요청 재시도와 명시적 최신 화면 확인을 보완했다. [검증 기록](RECOVERY_LOCK_REVIEW_2026_08_31.md)
2. [x] 원본 업로드·다운로드·삭제의 동시 요청 및 계정 정지 시점에 대한 권한·보존 검증. 늦은 권한 변경·삭제 상태 재확인, 조건부 저장·삭제 결정, 처리 중 업로드의 삭제 충돌, 레거시 삭제 실패 후 접근 차단을 보완했다. [검증 기록](FILE_OPERATION_REVIEW_2026_09_01.md)
3. [x] 상담 FLOW의 단계별 권한과 중복 요청 보호를 기존 테스트와 대조해 누락된 회귀 검증 보완. 처리 중 정지·권한 변경, 요청 번호의 다른 계정·내용·첨부 재사용, AI 전송 직전 권한 재확인을 보완했다. 상담 취소·발송 확인 기록의 누락된 검증도 추가했다. [검증 기록](FLOW_PERMISSION_REVIEW_2026_09_01.md)

승인된 순차 점검 3항목의 코드 점검을 모두 마쳤다. 최종 운영 반영·자동 후속 실행 일시 중지 결과는 Sites 배포 이력과 `outputs/release/flow-permissions-deployment.json`에 기록한다. 별도 사용자 요청 전에는 이 목록에 새 항목을 추가하거나 자동 점검을 재개하지 않는다.

위 점검이 완료되면 임의의 기능이나 반복 업무를 추가하지 않는다. 사용자 결정이 필요한 다음 사항은 기존 설정을 유지하고, 실제로 작업의 진행을 막을 때만 구체적인 대상과 영향 범위를 제시한다.

## 사용자 결정 또는 별도 범위가 필요한 일

- 실제 파트너 한 명을 선정한 가입·승인·로그인 실사용 검증과 연락처 확인.
- 진행번호·담당 ID가 없는 과거 원본의 수동 배정, 보관 기간·삭제 정책 결정, 실제 데이터 이관·삭제.
- 이메일·카카오톡 발송, 일정 양방향 동기화, 음성 자동전사, 전자서명·입금 조회 연결.
- 유료 AI·외부 처리의 키·잔액·모델·기업별 자료 전송 및 비용 승인. 메일 소유권 인증·MFA 도입 정책.

코드 개선 완료와 실제 운영 절차 완료를 구분한다. 중요한 정책 결정을 임의로 정하거나 고객에게 연락하지 않는다.

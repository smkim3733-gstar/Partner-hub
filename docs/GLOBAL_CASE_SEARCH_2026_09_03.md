# 권한 내 기업·신청번호 검색

2026-09-03. 사용자의 연속 개발 요청으로 상단에 표시만 되고 동작하지 않던 검색 입력을 현재 계정이 조회할 수 있는 진행 목록에 연결했다.

## 변경

- 기업명 또는 전체 신청번호로 진행을 찾고 해당 기업 진행 화면으로 이동한다.
- 화면에 표시하는 신청번호의 마지막 8자리도 정확히 일치하면 검색할 수 있다.
- 공백·대소문자·호환 문자를 정규화한다. 기업명이 같은 반복 신청이나 부분검색 결과가 여러 건이면 임의로 선택하지 않고 신청번호 입력을 안내한다.
- 검색 후보와 자동완성은 서버가 현재 계정에 반환한 `cases` 목록만 사용한다. 검색 전용 API나 전체 고객 조회 경로를 추가하지 않았다.
- 입력, 실행 버튼, 검색 영역을 의미 있는 HTML 요소로 연결하고 키보드 Enter 실행을 지원한다.

## 검증 경계

- 자동 테스트 245개, 타입검사, lint, 프로덕션 빌드 통과.
- 전체 신청번호·표시 번호·정규화한 기업명·반복 신청의 모호성·결과 없음·권한 내 후보 제한을 회귀검증한다.
- 격리 workerd/D1/R2 검사 129개 통과. 실제 쓰기·메일·유료 AI·외부 요청은 0건이다. localhost `/` 응답은 HTTP 200이다.
- 사용자가 브라우저 조작 검증을 요청하지 않아 실제 검색 입력·선택 화면의 수동 완료 판정은 하지 않았다.
- 서버 API, DB/R2 스키마, 계정 권한, 공개범위, 보관·삭제 정책은 변경하지 않았다. GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다. 반영 뒤 결과는 `outputs/release/global-case-search-deployment.json`을 기준으로 한다.

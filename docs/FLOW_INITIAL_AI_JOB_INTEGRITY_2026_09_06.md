# 상담 FLOW 최초 AI 작업 삽입 무결성

기준일: 2026-09-06

## 문제·적용

후속 FLOW revision은 새 작업을 무증거 대기 상태로만 추가했지만 D1 신규 루트 행은 기본 envelope만 검사해 처음부터 완료·실패 작업과 조작한 공급자 증거를 넣을 수 있었다. 이제 추가형 `0044` 삽입 트리거가 최초 행의 모든 AI 작업에도 같은 시작 규칙을 적용한다.

## 최초 삽입 경계

- 최초 FLOW 행의 작업은 `queued` 또는 `blocked`만 허용한다.
- 새 작업에는 시작·완료시각, 연결 보고서, 성공 증거, 현재 실패 증거와 실패 이력이 없어야 한다.
- 정상 `queued` 초기 작업과 작업이 없는 기존 최초 저장은 계속 허용한다.
- 이후 성공·실패 증거는 `0043`의 처리 중 → 완료·실패 전이에서만 들어간다.
- 애플리케이션 커밋과 D1 직접 삽입이 같은 규칙을 사용한다.
- 기존 행과 운영 자료를 변경하지 않는 추가형 트리거만 설치한다.

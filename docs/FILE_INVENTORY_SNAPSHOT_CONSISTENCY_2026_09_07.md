# 관리자 파일 재고 단일 D1 스냅샷 일관성

## 결과

대표 파일 재고의 페이지 목록과 체크섬 적용 현황을 하나의 SQLite 문장으로 조회한다. 조회 중 새 파일 원장이나 체크섬 원장이 추가돼도 한 응답의 목록과 적용 현황은 같은 D1 읽기 스냅샷만 나타낸다. 화면의 단일 점검시각이 서로 다른 두 데이터 시점을 하나처럼 보이게 하지 않는다.

기능 커밋은 `30bc0beea082e16ba1ba7b24356d7d737fe87950`이다.

## 재현과 수정

- 수정 전에는 목록 문장의 결과가 반환된 직후 새 SHA-256 원장을 삽입하면 목록에는 기존 파일 1건만 있지만 뒤이어 실행된 적용 현황 문장은 SHA-256 2건을 반환했다.
- 목록 후보·상태 분류·필터·키셋 페이지와 기업자료·FLOW 체크섬 증명 집계를 공통 CTE를 가진 단일 문장으로 결합했다.
- 목록 행과 적용 현황 전용 행을 명시적으로 구분한다. 적용 현황 행은 목록이 비어 있어도 정확히 한 건을 반환한다.
- 적용 현황 전용 행이 없거나 둘 이상이거나 네 건수 중 하나가 음수·비정수이면 안전한 503으로 중단한다.
- 기존 25건 페이지, 26번째 다음 커서 판정, 생성시각·ID 내림차순, 상태 필터와 커서 필터 결속을 유지한다.

## 정보 보호와 저장 경계

스키마와 운영 데이터를 변경하지 않는다. 집계는 D1 메타데이터만 읽고 R2 본문·객체 메타데이터를 조회하지 않는다. SHA-256 값, ETag, R2 저장 키, 요청 지문, 원문도 응답에 포함하지 않는다. 두 문장을 하나로 합쳐 D1 왕복은 줄지만 기존 목록과 적용 현황이 읽는 원장 범위는 바꾸지 않는다.

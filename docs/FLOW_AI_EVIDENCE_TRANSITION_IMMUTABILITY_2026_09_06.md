# 상담 FLOW AI 증거·감사 전이 불변성

기준일: 2026-09-06

## 문제·적용

저장 payload의 현재 구조와 증거·감사 연결이 정상이어도 후속 일반 저장이 기존 공급자 증거, 실패 이력 또는 감사기록을 서로 맞춰 바꾸거나 작업 전체를 지울 수 있었다. 이제 FLOW 커밋은 이전 revision과 다음 revision을 직접 대조해 이미 저장된 AI 관측 사실과 감사 이력을 보존한다.

## 저장 전이 경계

- 기존 감사 배열은 순서와 내용을 유지하는 접두부가 되어야 하며 새 기록만 뒤에 추가할 수 있다.
- 기존 작업은 삭제할 수 없다.
- 성공 증거는 `processing`에서 `complete`로 전이할 때만 처음 추가할 수 있고, 저장 뒤에는 변경하거나 제거할 수 없다.
- 현재 실패 증거는 `processing`에서 `failed`로 전이할 때만 처음 추가할 수 있다.
- 실패 증거가 있는 작업의 정상 재시도는 그 증거를 변경 없이 이력 끝으로 한 번 이동하는 전이만 허용한다.
- 기존 실패 이력은 순서·내용을 유지하며 일반 저장이 임의로 추가하거나 변경·제거할 수 없다.
- 구조상 정상인 모델명·HTTP 상태·요청 ID·감사 상세 변조와 기존 작업 삭제를 모두 D1 쓰기 전에 실패 폐쇄한다.

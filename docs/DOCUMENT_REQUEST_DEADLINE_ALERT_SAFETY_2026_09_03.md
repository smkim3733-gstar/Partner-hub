# 서류요청 제출기한 알림 안전성

2026-09-03 기준. 서류요청 후속 업무의 제출기한 상태가 실제 선택 날짜와 일치하도록 보완한 기록이다.

## 확인한 문제

- 신규 서류요청은 선택한 제출기한과 관계없이 후속 업무를 항상 `upcoming`·`보통`으로 만들었다.
- 기존 요청서류에 빠진 제출기한을 나중에 지정해도 표시 문구만 바뀌고 기한 상태와 우선순위는 갱신되지 않았다.
- 따라서 오늘 마감 또는 이미 지난 요청도 상단·메뉴의 `확인 필요` 알림에서 빠질 수 있었다.

## 적용한 동작

- 제출기한을 한국시간 `Asia/Seoul`의 현재 날짜와 비교해 `overdue`, `today`, `upcoming`으로 분류한다.
- 신규 서류요청의 후속 업무는 검증 단계에서 확정한 같은 기한 상태를 저장한다.
- 빠진 제출기한을 보정할 때 관련된 `기한 확인` 업무의 표시 날짜·기한 상태·우선순위를 함께 갱신한다.
- 오늘 마감과 기한 지연은 `긴급`, 미래 기한은 `보통`으로 표시한다.
- 유효하지 않은 날짜나 현재 시각은 저장 전에 거절한다.

## 운영 경계

- 기존에 날짜가 지정된 업무를 일괄 수정하지 않는다.
- 사용자가 신규 요청을 저장하거나 빠진 기한을 직접 지정할 때만 해당 화면 상태가 바뀐다.
- 알림 집계 기준, 서버 API, DB/R2 스키마, 인증·권한·보관 정책은 변경하지 않았다.
- 실제 운영 데이터 쓰기, 메일 발송, 유료 AI 호출, 외부 요청은 검증 중 모두 0건이다.

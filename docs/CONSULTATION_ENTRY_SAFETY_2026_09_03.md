# 상담 등록 입력 안전성

2026-09-03 기준 상담 등록 화면과 저장 직전 검증을 같은 허용값으로 정리했다.

## 변경 내용

- 새 상담은 상담방식·상담상태·후속조치를 자동 선택하지 않는다.
- 파트너 허브 일정 추가는 꺼진 상태로 시작하며, `일정 확정`을 선택한 뒤 사용자가 직접 켜야 한다.
- 상담 제목은 공백을 정리하고 필수값과 150자 제한을 화면·저장 경계에서 함께 검증한다.
- 상담방식·상담상태·후속조치·일정 공개범위는 공용 허용 목록에 포함된 값만 저장한다.
- `상담 완료`가 아닌 상태에서는 후속조치를 제거하고, `일정 확정`이 아닌 상태에서는 일정 추가를 해제한다.
- 알 수 없는 후속조치가 일반 내부업무로 바뀌어 저장되지 않도록 요청을 거절한다.
- 입력 오류가 나면 제목·일시·상담방식·상담상태의 해당 입력으로 초점을 이동한다.

## 유지한 경계

- 기존 상담 기록과 일정 공유 선택지는 변경하지 않았다.
- 일정 추가는 파트너 허브 내부 일정만 준비하며 외부 캘린더에 자동 등록하거나 발송하지 않는다.
- 서버 API, D1/R2 스키마, 인증·권한, 자료 보관·삭제 정책은 변경하지 않았다.
- 운영 데이터 쓰기, 메일 발송, 유료 AI 요청, 외부 네트워크 요청 없이 가상 입력으로 검증했다.

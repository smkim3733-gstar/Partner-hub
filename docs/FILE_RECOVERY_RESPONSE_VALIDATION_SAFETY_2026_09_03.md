# 원본 회수 응답 검증 안전성

2026-09-03 기준으로 대표의 기존 신청 원본 회수 요청이 서버 응답을 확인하는 경계를 보강했다.

## 변경 범위

- HTTP 응답 본문을 `unknown`으로 읽고 일반 객체인지 확인한다.
- HTTP 성공과 `{ ok: true }`가 함께 확인된 경우에만 회수 저장 완료로 표시한다.
- 서버가 제공한 비어 있지 않은 오류 문구는 그대로 전달한다.
- 비-JSON 응답과 구조가 손상된 성공 응답은 내부 파싱 내용을 노출하지 않고 같은 원본·확인 내용으로 재시도하도록 안내한다.

## 유지한 안전 경계

- 요청이 한 번 전송된 뒤에는 응답 유실이나 검증 실패가 있어도 편집 잠금을 유지한다.
- 재시도는 최초 확인 때 고정한 계정·원본·진행·상태 버전·사유와 같은 요청 본문을 사용한다.
- 성공 여부가 불확실한 동안 새 상태를 가져오거나 다른 원본으로 바꾸지 않는다.
- 서버 회수 명령, 인증·권한, 원본 보존, 확인 이력, DB/R2 스키마와 보관 정책은 변경하지 않았다.

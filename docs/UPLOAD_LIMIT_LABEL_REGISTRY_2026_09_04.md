# 업로드 제한 안내 공용화

## 목적

기업자료·협업신청·상담 FLOW·AI 사전점검 화면과 서버 오류의 파일 크기·개수 안내가 실제 제한 상수와 어긋나지 않도록 한다.

## 적용 범위

- 기업자료 파일당 25MB는 `MAX_COMPANY_FILE_BYTES`에서 MB 표시값을 계산한다.
- AI 근거자료 파일당·합계 8MB와 최대 8개는 AI 근거자료 정책에서 표시값을 계산한다.
- 전사문 5MB와 음성 25MB는 전사문 정책에서 표시값을 계산한다.
- 기업자료함, 협업신청 첨부, 상담 FLOW 근거자료, 신청자료 검토, 생성 사전점검 화면과 서버 오류가 같은 값을 사용한다.
- 화면·서버 코드의 `5MB`, `8MB`, `8개`, `25MB` 직접 선언을 제거했다.

## 유지한 경계

실제 파일 크기와 개수 제한, 허용 형식, 실제 내용 검사, 인증·권한·동의, D1/R2 스키마와 보관 정책은 변경하지 않았다. 기존 저장 자료와 운영 데이터를 변경하지 않았다.

## 재발 방지

기업자료·AI 근거자료·전사문·음성의 계산된 표시값, 화면의 공용 상수 사용과 기존 오류 문구를 자동 테스트로 고정했다.

## 검증·운영 반영

- 전체 자동 테스트 453개 통과
- 격리 workerd/D1/R2 검사 129개 통과
- TypeScript 타입검사, 전체 lint, 프로덕션 빌드 통과
- 격리검사 중 운영 쓰기, 메일, 유료 AI, 외부 요청 0건

2026-09-04 자동 운영 승인 원칙에 따라 커밋 `6cadc2b`를 GitHub `main`과 공개 Sites 버전 94에 반영했다. 공개 범위와 D1 `DB`, R2 `AI_SOURCE_FILES` 연결을 유지했으며 운영 화면 3곳의 HTTP 200, 기업자료·상담 FLOW API의 익명 HTTP 401과 비공개 보안 헤더를 확인했다. 배포 결과는 `outputs/release/upload-limit-label-registry-deployment.json`을 기준으로 삼는다.

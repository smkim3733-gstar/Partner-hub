# 상담 FLOW AI 결과 보고서 무결성

기준일: 2026-09-06

## 보완 내용

정상 AI 완료 상태와 성공 증거를 갖춘 전이에 기존 보고서 변조, 여분 보고서 삽입 또는 완료 작업과 무관한 결과 보고서를 섞을 수 있던 공백을 차단했다.

- `processing → complete` 전이 한 건은 새 결과 보고서 한 건만 추가한다.
- 기존 보고서 배열의 순서와 각 항목을 그대로 보존한다.
- 결과 ID와 작업 `reportId`를 `${job.id}-result`에 결속한다.
- 보고서 단계·단계별 버전·제목·생성시각·생성자·AI 출처를 완료 작업과 결속한다.
- 1차 결과는 원본 참조 없이 분석 포인터를 새 결과로 교체하고, 4차 결과는 작업의 녹취·1차 보고서 근거를 그대로 사용한다.
- 애플리케이션 커밋 검사와 추가형 `0062` D1 트리거가 같은 규칙을 독립 검사한다.

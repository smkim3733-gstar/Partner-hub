# 상담 FLOW AI 결과 저장 상한 무결성 경계

기준일: 2026-09-05

## 확인한 문제

Claude 응답 본문은 80,000자까지 허용했지만 저장 직전에 내부 초안 안내문과 지침 버전을 앞에 붙였다. 원문이 상한에 가까우면 최종 보고서가 저장 필드 상한을 초과해, 외부 AI 호출 이후 D1 결과 저장이 실패하고 작업이 처리 중 상태로 남을 수 있었다.

AI 작업을 처리 중으로 전환하기 전에 보고서와 감사기록의 남은 용량도 확인하지 않았다. 이미 결과 저장 한도에 도달한 진행이 불필요한 외부 요청을 시작할 가능성이 있었다.

## 적용한 경계

- 보고서 본문, 녹취, AI 원문, AI 작업 사유, 감사 상세의 저장 상한을 공용 상수로 통합했다.
- Claude 원문 검증 뒤 내부 안내문까지 결합한 최종 본문을 다시 확인하고 80,000자를 넘으면 정식 보고서로 저장하지 않는다.
- AI 작업을 처리 중으로 전환하기 전에 보고서와 감사기록의 결과 저장 용량을 확인한다.
- 결과 확정 시 최신 상태의 보고서·파일·감사기록 용량을 다시 확인한다.
- 실패 사유와 그 사유를 포함하는 감사 상세도 각각의 저장 상한을 넘지 못하게 한다.
- 용량 부족은 HTTP 409, 개별 결과 필드 초과는 HTTP 413으로 실패 폐쇄한다.

## 검증

- 감사기록이 한도에 도달한 작업은 처리 중으로 바뀌기 전에 거절한다.
- 80,000자를 초과한 직접 AI 결과는 무결성이 깨진 상태를 반환하기 전에 거절한다.
- 원문은 허용 범위지만 내부 안내문 결합 뒤 80,000자를 넘는 모의 Claude 응답은 실패 작업으로 정상 저장하고 보고서를 만들지 않는다.
- 격리 Workers+D1에서 감사기록 4,000개인 대기 작업은 외부 요청 전에 HTTP 409로 차단하며 작업 상태를 `queued`로 유지한다.
- Node 자동 테스트 583/583 통과.
- 격리 workerd+D1+R2 검사 370/370 통과.
- 타입검사, 전체 lint, 포맷 검사, 프로덕션 빌드 통과.
- 로컬 프로덕션 `/`, `/account`, `/account/setup` HTTP 200과 CSP·`DENY`·`nosniff`·`no-referrer` 확인.
- 실제 운영 쓰기, 메일 발송, 유료 AI 요청, 외부 요청 0건.

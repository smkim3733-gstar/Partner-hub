`save_report` 명령을 명령 ID 기반 새 보고서 정확히 한 건, 선택 첨부 최대 한 건과 단계별 후속 상태에 결속했다. 기존 보고서·파일 이력은 보존하며, 보고서의 ID·단계·버전·제목·생성시각·생성자·수동 생성 표시·근거 참조와 첨부의 ID·용도·생성시각을 애플리케이션 커밋 검사와 추가형 `0079` D1 트리거에서 독립 강제한다. 1차 보고서는 분석 포인터를 새 보고서 하나로 초기화하고, 나머지 단계는 기존 분석을 보존한다. 5차 이상은 확정 솔루션과 필수서류 연결도 정확히 유지한다.

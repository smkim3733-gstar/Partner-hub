# ChatGPT 안정 ID-회원 결속 무결성

기준일: 2026-09-05

## 해결한 문제

파트너의 ChatGPT 포털 접속은 인증 공급자가 전달한 이메일과 활성 회원 이메일만 비교했다. 동일 이메일이 다른 ChatGPT 계정에 다시 할당되면 기존 회원의 안정 사용자 ID와 무관하게 접근이 이어질 수 있었다.

## 적용 경계

- `portal_chatgpt_member_bindings` 추가형 D1 표에 회원 ID와 ChatGPT 안정 사용자 ID의 단방향 SHA-256 키를 1:1로 저장한다. 원문 사용자 ID는 이 표와 `portal_state`에 저장하지 않는다.
- ChatGPT 자가등록은 승인대기 회원 저장과 안정 ID 결속을 하나의 D1 트랜잭션으로 처리한다. 어느 한쪽이 실패하면 명단과 `membersRevision`도 함께 롤백한다.
- 결속 전 기존 활성 회원은 현재 이메일이 정확히 일치하는 첫 정상 접속에서 안정 ID를 한 번만 결속한다. 두 계정의 동시 선점은 D1 고유 제약으로 한 계정만 성공한다.
- 결속 뒤에는 이메일이 아니라 안정 사용자 ID로 회원을 찾는다. 같은 이메일의 다른 ID는 거절하고, 같은 안정 ID의 공급자 이메일 변경은 기존 회원 접근을 유지한다.
- 대표가 회원 이메일을 변경하거나 회원을 삭제하면 안정 ID 결속도 포털 상태와 같은 트랜잭션에서 제거한다. 단순 정지·재활성화는 결속을 보존한다.
- 결속 삭제 실패 시 회원 상태와 revision을 함께 롤백한다.

## 의도적으로 하지 않은 일

- 결속 전 기존 회원의 과거 ChatGPT 사용자 ID를 추정하거나 운영 데이터를 일괄 이관하지 않는다. 기존 회원은 첫 정상 접속에서 결속된다.
- 대표 관리자 인증 경로, 비밀번호 인증, 권한, 세션 수명, 공개 범위, D1/R2 연결과 보관·삭제 정책은 변경하지 않는다.
- 실제 회원·고객 자료·운영 D1/R2를 읽거나 변경하지 않고 외부 요청·메일·유료 AI를 실행하지 않는다.

## 검증

- Node 전체 회귀 테스트 482개 통과
- 격리 workerd/D1/R2 검사 170개 통과, 외부 요청·운영 쓰기 0건
- 동일 이메일의 다른 ChatGPT ID 접근·재등록 차단 확인
- 기존 활성 회원의 최초 결속과 원문 ID 미저장 확인
- 공급자 이메일 변경 뒤 안정 ID 접근 유지 확인
- 정지 시 결속 보존, 이메일 변경·회원 삭제 시 원자적 제거 확인
- 결속 등록·삭제 장애 때 회원 상태와 revision 롤백 확인
- 타입검사, 전체 lint, 프로덕션 빌드와 로컬 `/`, `/account`, `/account/setup` HTTP 200 확인

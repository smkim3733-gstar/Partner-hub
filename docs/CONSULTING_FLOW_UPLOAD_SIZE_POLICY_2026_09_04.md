# 상담 FLOW 목적별 업로드 크기 정책

## 목적

상담 FLOW 화면 안내와 서버의 공통·업무별 업로드 크기 제한을 같은 정책에서 관리하고, 과대 파일의 전체 내용 판독 전에 크기를 거절한다.

## 확인된 문제

- 모든 공용 첨부 입력이 최대 25MB로 표시되어 AI 근거자료의 실제 파일당·합계 8MB 제한과 안내가 어긋났다.
- 서버가 공통 25MB 검사 뒤 업무 규칙에서 AI 근거자료 8MB와 전사문 5MB를 확인했다.
- OOXML·TXT는 실제 형식 검사에서 전체 파일을 읽으므로 목적·크기 거절보다 내용 판독이 먼저 실행되면 불필요한 메모리 사용이 발생할 수 있었다.

## 적용 범위

- AI 근거자료는 새 파일 1개당 8MB, 전사문 DOCX·TXT는 5MB, 보조 음성과 나머지 상담 FLOW 첨부는 25MB로 공용 정책에 선언한다.
- 공용 파일 입력과 녹취 화면이 같은 정책에서 MB 안내를 계산한다.
- 서버는 명령의 첨부 허용 여부, 동의, 목적별 크기를 먼저 검사한 뒤 실제 파일 형식을 판독한다.
- AI 근거자료의 기존 8개·합계 8MB 제한은 유지한다.

## 유지한 경계

허용 파일 형식, 실제 내용·확장자 일치 검사, 인증·권한·동의, 멀티파트 전체 요청 상한, D1/R2 스키마와 보관 정책은 변경하지 않았다. 기존 저장 파일을 변경·삭제하거나 자동 이관하지 않는다.

## 재발 방지

목적·문서/음성 슬롯별 크기, AI 근거자료 8MB 초과 거절, 화면의 공용 크기 정책 사용과 라우트의 검사 순서를 자동 테스트로 고정했다.

# 모바일 기업·신청번호 검색

2026-09-03. 사용자의 연속 개발 요청으로 데스크톱 상단에서만 보이던 권한 내 기업·신청번호 검색을 모바일 메뉴에도 제공했다.

## 변경

- 검색 입력·실행 버튼·권한 내 자동완성을 공용 폼으로 분리해 데스크톱과 모바일이 같은 검색 계약을 사용한다.
- 모바일 메뉴를 열면 메뉴 목록보다 먼저 검색할 수 있다. 검색 성공 시 기존 이동 경로가 메뉴를 닫고 해당 진행 화면을 연다.
- 데스크톱과 모바일 입력·자동완성 목록에 서로 다른 ID를 부여해 한 화면에 함께 렌더링돼도 연결이 충돌하지 않는다.
- Enter 제출, 명시적 검색 버튼, 입력과 버튼의 접근 가능한 이름을 유지한다. 검색 후보는 기존처럼 서버가 현재 계정에 반환한 진행만 사용한다.

## 검증 경계

- 자동 테스트 251개, 타입검사, lint, 프로덕션 빌드 통과.
- 검색 폼의 키보드 제출, 접근 가능한 이름, 권한 내 자동완성 항목, 데스크톱·모바일 고유 ID를 회귀검증한다.
- 격리 workerd/D1/R2 검사 129개 통과. 실제 쓰기·메일·유료 AI·외부 요청은 0건이다.
- localhost `/` 응답은 HTTP 200이다.
- 서버 API, DB/R2, 권한·보관 정책은 변경하지 않았다. 사용자가 브라우저 조작 검증을 요청하지 않아 실제 모바일 터치·키보드 조작 완료 판정은 하지 않았다.
- GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다. 반영 뒤 결과는 `outputs/release/mobile-case-search-deployment.json`을 기준으로 한다.

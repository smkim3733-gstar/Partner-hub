# 상담 FLOW AI 작업 대상 무결성

기준일: 2026-09-06

## 보완 내용

새 사용자 명령이 없는 내부 AI 갱신 한 번에 여러 기존 작업을 함께 바꾸거나 작업 배열을 추가·삭제·재정렬할 수 있던 공백을 차단했다.

- 애플리케이션 커밋 검사는 내부 AI 갱신에서 작업 배열의 길이와 ID 순서를 보존한다.
- 같은 갱신에서 값이 달라지는 기존 작업은 정확히 한 건만 허용한다.
- 추가형 `0065` D1 트리거가 앱 경로를 우회한 직접 SQL에도 같은 대상 규칙을 강제한다.
- 사용자 명령이 새로 추가되는 정상 작업 생성과 내용이 동일한 멱등 재시도는 기존 명령 검증 경로를 유지한다.
- 기존 두 작업의 청구·완료 회귀검사는 운영 실행기처럼 한 건씩 순차 전이하도록 고쳤다.

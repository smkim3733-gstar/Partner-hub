# 상담 FLOW 비명령 AI 상태 전이 무결성

기준일: 2026-09-06

## 보완 내용

새 사용자 명령이 없는 내부 AI 갱신으로 재시도나 임의 작업 상태 변경을 수행해 명령 ID·감사기록·멱등 영수증 결속을 우회할 수 있던 공백을 차단했다.

- 비명령 내부 갱신은 대기 작업의 처리 시작·보류와 처리 중 작업의 보류·실패·완료만 허용한다.
- 실패·보류·처리 중 작업을 다시 대기로 돌리는 재시도는 사용자 명령 ID, 같은 ID의 감사기록과 명령 영수증을 반드시 추가해야 한다.
- 애플리케이션 커밋 검사가 이전·다음 작업 상태 조합을 직접 검증한다.
- 추가형 `0066` D1 트리거가 앱 경로를 우회한 직접 SQL에도 같은 상태 전이 규칙을 강제한다.
- 기존 작업 배열 길이·ID 순서·단일 대상 결속은 `0065` 경계를 그대로 유지한다.

# 상담 FLOW 근거자료 직접 저장 효과 무결성

기준일: 2026-09-06

## 보완 내용

`save_source` 명령의 파일 변경을 기존 파일 보존과 선택한 새 수동 근거자료 최대 한 건에 정확히 제한했다.

- 기존 파일의 값과 순서를 모두 보존한다.
- 수동 첨부가 없으면 파일 목록을 그대로 유지한다.
- 수동 첨부가 있으면 새 파일 한 건만 추가하고 용도를 `source`, 생성시각을 FLOW 갱신시각으로 고정한다.
- 신청자료 불러오기에서만 사용하는 `intakeFileId`를 수동 첨부에 넣을 수 없다.
- 기존 근거자료 보관 제외, 파일 추가·삭제·재정렬을 원문 저장과 함께 수행하는 것을 거절한다.
- 애플리케이션 커밋 검사와 추가형 `0076` D1 트리거가 같은 효과를 독립 강제한다.

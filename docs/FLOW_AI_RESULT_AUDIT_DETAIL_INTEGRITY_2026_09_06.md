# 상담 FLOW AI 결과 감사문구 무결성

기준일: 2026-09-06

## 보완 내용

AI 작업의 완료·실패·보류 상태와 증거에 맞는 감사 ID·시각·행위가 있어도 상세 문구를 다른 결과나 사유처럼 임의 작성할 수 있던 공백을 차단했다.

- 공용 `flowAiResultAuditDetail` 함수가 단계, 결과 상태, 실패·보류 사유에서 감사문구를 생성한다.
- 완료는 단계별 보고서명과 자동 저장·담당 파트너 공유 문구를 사용한다.
- 실패·보류는 단계별 보고서명, 상태와 작업에 저장된 정확한 사유를 사용한다.
- 애플리케이션 커밋 검사는 각 `processing → blocked/failed/complete` 전이의 새 감사문구를 검증한다.
- 추가형 `0064` D1 트리거는 기존 감사 누락·시각 오류 검사의 책임을 유지하면서 올바른 결과 감사가 존재할 때 상세 문구를 독립 검사한다.
- 과거 감사기록은 바꾸지 않아 기존 데이터 호환성을 유지한다.

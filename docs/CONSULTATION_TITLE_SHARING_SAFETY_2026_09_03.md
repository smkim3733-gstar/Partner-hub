# 상담 제목·일정 공개범위 입력 안전성

2026-09-03 기준. 새 상담 기록의 제목과 허브 일정 공개범위를 사용자가 실제 업무에 맞게 직접 입력하도록 보완한 기록이다.

## 확인한 문제

- 새 상담 제목에 서비스명 기반의 일반 문구가 자동 입력되어 실제 상담 목적을 확인하지 않고도 기록을 만들 수 있었다.
- 허브 일정 추가를 켜면 공개범위가 `전체 파트너 시간 공유 · 담당 파트너 상세공개`로 이미 선택되어 있었다.
- 공개 옵션의 실제 권한 의미는 화면에 안내됐지만, 일정 저장 전에 사용자의 명시적인 범위 선택은 요구하지 않았다.

## 적용한 동작

- 새 상담 제목은 빈 상태로 시작하며 기존 제목 필수·150자 제한을 저장 경계에서 다시 검증한다.
- 새 상담의 일정 공개범위도 빈 상태로 시작한다.
- `일정 확정` 상태에서 허브 일정 추가를 선택한 경우에만 세 공개범위 중 하나를 직접 선택해야 한다.
- 선택하지 않으면 오류를 표시하고 공개범위 선택창으로 초점을 옮긴다.
- 허브 일정을 추가하지 않거나 일정 확정이 아닌 상태는 일정 생성 없이 `private`로 정규화한다.
- 일정 추가를 끄거나 상담상태를 일정 확정에서 바꾸면 이전 공개범위를 지운다.

## 운영 경계

- `전체 파트너 시간 공유`, `담당 파트너 상세공개`, `내부만 공개`의 기존 의미와 접근 권한은 바꾸지 않았다.
- 기존 상담·일정 기록은 수정하지 않는다.
- 서버 API, DB/R2 스키마, 인증·권한·보관 정책은 변경하지 않았다.
- 실제 운영 데이터 쓰기, 메일 발송, 유료 AI 호출, 외부 요청은 검증 중 모두 0건이다.

- 일정 미추가와 호환되지 않는 상담상태가 일정 없이 `private`로 정규화되는 경계 확인.
- 관련 테스트 13개 통과.
- 전체 자동 테스트 284개 통과.

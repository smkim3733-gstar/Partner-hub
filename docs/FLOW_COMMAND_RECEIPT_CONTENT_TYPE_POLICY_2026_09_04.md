# 상담 FLOW 명령 영수증 Content-Type 정책

## 목적

상담 FLOW 첨부 명령의 멱등 영수증이 브라우저 제공 MIME 차이 때문에 같은 파일·같은 명령을 충돌로 오판하지 않도록 한다.

## 적용 범위

- 첨부 이름·크기·SHA-256과 명령 내용은 기존처럼 영수증 지문에 포함한다.
- 첨부 MIME은 브라우저 값 대신 검증된 확장자의 공용 업로드 형식 등록표에서 결정한다.
- 신규 영수증에는 계정 키와 정규화된 단일 지문만 저장한다. 배포 호환용 이전 지문은 D1 FLOW payload에 저장하지 않는다.
- 신규 영수증으로 완료된 요청은 같은 이름·크기·바이트·명령이면 브라우저 MIME이 달라도 안전 재시도로 인정한다.
- 배포 전 저장된 영수증은 현재 재시도의 브라우저 MIME이 같을 때 이전 지문도 대조해 기존 복구를 유지한다.
- 계정, 명령 내용, 파일 이름·크기·바이트가 달라지면 기존처럼 HTTP 403 또는 409로 거절한다.

## 유지한 경계

업로드 허용 형식, 실제 내용 검사, 크기·개수, 파일명, 권한·동의, FLOW 단계, R2 저장 MIME·키, D1 스키마와 보관 정책은 변경하지 않았다. 기존 FLOW payload를 일괄 변경하지 않았다.

# 상담 FLOW 일정 취소 효과 무결성

기준일: 2026-09-06

`cancel_meeting` 명령을 영수증에 기록한 `targetId`의 예정 상담 정확히 한 건에 결속했다. 명령 지문이 요청한 상담 ID와 내용을 묶는 기존 경계에 더해, 서버가 같은 상담 ID를 별도 영수증 필드로 저장하므로 저장 결과만 검사하는 애플리케이션과 D1도 선택 대상을 독립 확인할 수 있다. `complete_meeting`과 `cancel_meeting`에는 유효한 `targetId`를 필수로 하고 다른 action에는 허용하지 않으며, 저장된 대상 이력은 이후 revision에서 바꿀 수 없다.

애플리케이션 커밋 검사와 추가형 `0083` D1 트리거는 대상 상담이 직전 상태에서 `scheduled`이고 완료시각이 없었는지, 결과가 `cancelled`이며 완료시각도 없는지 검증한다. 일정 배열의 길이·순서·비대상 상담을 보존하고 대상에서는 상태·메모 외 필드를 바꾸지 못하게 한다. 기존 메모 삭제, 새 메모의 빈값·앞뒤 공백, 대상 바꿔치기, 이미 취소된 상담 재취소, 비참석 파트너의 취소 기록을 거절한다. 관리자는 대표 신원으로 취소할 수 있고 담당 파트너는 참석 범위가 `both` 또는 `partner`인 상담만 취소할 수 있다.

검증은 방어 전 이미 취소된 상담의 메모를 바꾸며 재취소하는 위조가 수락되는 실패를 먼저 재현했다. 보완 후 정상 취소와 대상 바꿔치기·재취소·대상 누락·비참석자 기록을 앱과 D1 양쪽에서 확인했다. Node 688/688, 관련 FLOW 검사 136/136, 집중 검사 94/94, 격리 workerd+D1+R2 510/510, 타입검사, lint, 포맷, 프로덕션 빌드, 로컬 Worker 화면 3곳 200·보호 API 3곳 401과 비공개 무저장 헤더를 통과했다. 검증 중 운영 데이터 쓰기·메일·유료 AI·외부 업무 API 호출은 0건이다.

# 서류요청 등록 입력 안전성

2026-09-03 기준 새 서류요청의 자동 선택과 실제 저장되지 않는 표시를 제거하고, 화면 입력과 현재 저장 계약을 일치시켰다.

## 변경 내용

- 새 서류요청은 빈 요청 목록에서 시작한다. 사업자등록증·크레탑 기업정보·최근 3개년 재무제표·부가가치세 과세표준증명은 추천으로만 표시한다.
- 추천 서류는 사용자가 `요청에 추가`를 눌러야 실제 요청 목록에 들어간다.
- 직접 입력한 서류명은 공백을 정리하고 150자 제한을 화면과 저장 직전 경계에 함께 적용한다.
- 현재 목록 또는 같은 진행의 요청중·보완필요 목록과 이름이 같은 서류는 추가 단계에서 바로 차단한다. 저장 직전 중복 제거도 유지한다.
- 요청 목록이 비었거나 모두 기존 요청과 겹치면 저장하지 않는다.
- 서류명·목록·제출기한 오류는 관련 입력으로 초점을 이동한다.

## 실제 저장 계약과 경계

- 이 화면이 저장하는 값은 서류명과 제출기한이다. 기존 화면의 `필수/선택` 표시는 이후 자료 카드·업무에 보존되지 않았으므로 제거했다.
- 필수자료 정책을 추가하려면 운영 데이터 모델과 처리 규칙 결정이 필요하므로 이번 변경에서 추정하거나 새 필드를 만들지 않았다.
- 기존 요청 자료·업무·일정, 서버 API, D1/R2 스키마, 인증·권한, 보관·삭제 정책은 변경하지 않았다.
- 기업대표에게 메일·메시지를 보내거나 외부 서비스를 호출하지 않는다.

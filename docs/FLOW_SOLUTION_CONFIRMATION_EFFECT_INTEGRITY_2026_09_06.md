# 상담 FLOW 진행솔루션 확정 효과 무결성

기준일: 2026-09-06

`confirm_solutions` 명령을 현재 근거에 맞는 최신 4차 심화보고서와 대표 행위자의 결정 정확히 한 건에 결속했다. 애플리케이션 커밋 검사와 추가형 `0084` D1 트리거는 명령 ID 기반 결정 ID, 최신 1차 보고서·최신 녹취를 근거로 한 가장 최근 4차 보고서, 서버 결정시각을 강제한다. 계약 체결 뒤 재확정과 담당 파트너 명의의 직접 저장도 거절한다.

확정 솔루션은 공백을 제거한 1~12개의 고유 문자열이어야 하며 각 항목은 80자 이내다. 추가 서류 필요 여부는 명시적 불리언만 허용하고 메모는 앞뒤 공백이 없는 2,000자 이내 문자열로 보존한다. 결정 객체는 `id`, `reportId`, `solutions`, `note`, `documentsNeeded`, `at` 여섯 필드만 갖도록 D1에서도 독립 검사한다.

검증은 방어 전 과거 4차 보고서, 담당 파트너 행위자, 위조 결정 ID·과거시각과 중복 솔루션을 조합한 저장이 수락되는 실패를 먼저 재현했다. 보완 후 정상 확정과 과거 보고서·회원 행위자·위조 메타데이터·중복 및 빈 솔루션을 앱과 D1 양쪽에서 확인했다. Node 689/689, 관련 FLOW 검사 137/137, 집중 검사 95/95, 격리 workerd+D1+R2 511/511, 타입검사, lint, 포맷, 프로덕션 빌드, 로컬 Worker 화면 3곳 200·보호 API 3곳 401과 비공개 무저장 헤더를 통과했다. 검증 중 운영 데이터 쓰기·메일·유료 AI·외부 업무 API 호출은 0건이다.

# 진행 기록 필드·담당 연결 무결성 경계

기준일: 2026-09-05

## 확인한 문제

진행 배열은 일반 객체와 고유 ID만 확인했다. 기업명·담당자명이 없거나 앞뒤 공백으로 오염된 진행, `partnerMemberId`가 문자열이 아니거나 현재 명단의 계정 하나에 정확히 연결되지 않는 진행도 관리자 일반 저장을 통과했다. 이런 상태는 진행 표시·담당자 변경·파트너 권한 투영·연결 업무 판정이 서로 다른 소유자를 가리키거나 고아 기록으로 남게 할 수 있었다.

## 적용한 경계

- 모든 진행의 기업명과 담당자명은 비어 있지 않은 앞뒤 공백 없는 문자열이어야 한다.
- 비어 있지 않은 `partnerMemberId`는 현재 회원 명단의 계정 ID 하나에 정확히 연결되어야 한다. 정지 계정도 기존 담당 기록 보존을 위해 유효한 연결로 본다.
- `partnerMemberId`가 없는 기존 이름 기반 기록과 빈 문자열로 명시한 대표 전담 기록은 기존 의미를 유지한다.
- 공용 순수 검증기를 서버 저장·조회와 클라이언트 최초 상태 응답에 함께 적용한다.
- D1의 상담 FLOW가 화면 상태에 투영된 뒤에도 같은 상태 무결성 검사를 다시 수행해 투영 결과의 고아 담당 연결을 관리자에게 반환하지 않는다.
- 조작 저장은 403, 이미 저장된 손상 상태는 파트너 조회 403, 관리자 조회와 일반 저장 503으로 격리한다.
- 운영 데이터 자동 수정, 기존 담당 재배정, D1/R2 스키마 변경은 수행하지 않았다.

## 검증

- 수정 전 재현: 빈 기업명·담당자명, `null` 또는 존재하지 않는 담당 ID가 관리자 저장 또는 파트너 투영 경계를 통과했다.
- 수정 후: 조작 저장 403, 손상 상태 파트너 조회 403, 관리자 조회·일반 저장 503.
- Node 자동 테스트 525/525 통과.
- 격리 workerd+D1+R2 검사 272/272 통과.
- 타입검사, 전체 lint, 프로덕션 빌드 통과.
- 로컬 프로덕션 `/`, `/account`, `/account/setup` HTTP 200과 화면 보안 헤더 확인.
- 실제 운영 쓰기, 메일 발송, 유료 AI 요청, 외부 요청 0건.

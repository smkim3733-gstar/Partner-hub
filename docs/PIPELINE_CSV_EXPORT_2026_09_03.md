# 진행현황 CSV 내보내기

2026-09-03. 사용자의 연속 개발 요청으로 상세 기획서의 관리자 `엑셀 내보내기` 항목 중 운영 진행현황을 Excel에서 열 수 있는 CSV로 구현했다.

## 변경

- 대표의 전체 진행현황 화면에 `운영 CSV 내보내기`를 추가했다. 현재 검색어·담당자·서비스·장기 미진행 필터를 모두 적용한 결과만 내려받는다.
- 서버가 대표에게 반환한 진행 목록에서 가상 예시 ID를 다시 제외한다. 파트너 화면에는 내보내기 버튼을 제공하지 않는다.
- 신청번호, 기업명, 서비스, 담당자, 파트너 유형, 현재 단계, 다음 행동, 최종 업데이트, 상담 횟수, 정체 일수, 긴급 여부, 진행 상태를 담는다. 계정 이메일·내부 계정 ID·신청 상세·원본 내용은 포함하지 않는다.
- UTF-8 BOM·CRLF·따옴표 이스케이프를 적용해 한글 Excel 호환성을 높였다. `=`, `+`, `-`, `@`로 시작하는 값은 수식으로 실행되지 않게 중화한다.
- 파일명 날짜는 한국시간 기준 `partner-hub-cases-YYYY-MM-DD.csv`로 만든다. 외부 서버 전송이나 운영 상태 변경은 없다.

## 검증 경계

- 자동 테스트 249개, 타입검사, lint, 프로덕션 빌드 통과.
- 한글 인코딩, 쉼표·따옴표, 수식 주입, 호출자가 넘긴 필터 결과만 포함하는 경계, 한국 날짜 파일명을 회귀검증한다.
- 격리 workerd/D1/R2 검사 129개 통과. 실제 쓰기·메일·유료 AI·외부 요청은 0건이다.
- localhost `/` 응답은 HTTP 200이다.
- 실제 Excel 프로그램의 열기·열 너비·사용자 다운로드 조작은 자동검증 범위가 아니다. GitHub 푸시와 공개 Sites 배포는 사용자 승인 전까지 수행하지 않는다. 반영 뒤 결과는 `outputs/release/pipeline-csv-export-deployment.json`을 기준으로 한다.

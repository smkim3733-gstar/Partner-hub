# ChatGPT 관리자 안정 ID 결속 무결성

기준일: 2026-09-05

## 문제

대표 관리자 권한이 고정 이메일만 확인하던 상태에서는 같은 이메일이 다른 ChatGPT 사용자 ID에 재할당되거나 전달 헤더가 잘못 연결될 때 새 계정이 관리자 권한을 이어받을 수 있었다. 버전 115의 회원 안정 ID 결속은 파트너 계정만 보호했으므로 관리자와 회원을 하나의 ID 소유권 경계로 통합할 필요가 있었다.

수정 전 회귀 재현에서는 기존 대표와 다른 안정 사용자 ID가 대표 이메일을 제시했을 때 관리자 상태 조회가 HTTP 200으로 성공했다.

## 적용한 경계

- 운영에서 대표 이메일로 처음 정상 접속한 ChatGPT 안정 사용자 ID를 SHA-256 단방향 해시로 저장하고 `owner / primary` 관리자 주체에 결속한다. 원본 사용자 ID는 저장하지 않는다.
- 결속 뒤에는 같은 안정 사용자 ID가 공급자 이메일 변경 후에도 관리자 권한을 유지한다. 대표 이메일을 제시하는 다른 사용자 ID는 HTTP 403으로 거절한다.
- 관리자와 회원의 결속을 `portal_chatgpt_identity_bindings` 한 테이블로 통합하고 사용자 키에 유일 제약을 둔다. 하나의 ChatGPT ID가 관리자와 파트너를 동시에 소유할 수 없다.
- 최초 관리자 결속은 충돌 시 덮어쓰지 않고 저장 뒤 소유권을 다시 확인한다. 동시 최초 요청에서도 정확히 한 ID만 관리자가 된다.
- D1 조회·결속 저장 실패는 이메일 권한으로 우회하지 않고 요청을 HTTP 500으로 실패시킨다.
- 대표 운영 이메일과 로컬 시험용 대표 이메일은 사이트 비밀번호 가입, ChatGPT 자가가입, 대표 직접등록, 기존 파트너 이메일 편집에서 모두 사용할 수 없다.
- 로컬 시험용 대표 이메일 우회는 요청 호스트가 정확히 `localhost`일 때만 유지하며 운영 결속으로 저장하지 않는다.
- 추가형 마이그레이션 `0013_chatgpt_identity_bindings.sql`은 버전 115 형식의 기존 회원 결속을 새 통합 테이블로 복사한다. 기존 행이나 운영 원본을 삭제하지 않는다.

## 배포와 복구 경계

현재 공개 운영본은 버전 107이므로 운영 D1에는 이 결속이 아직 적용되지 않았다. 버전 117을 배포한 뒤 대표가 기존 정상 ChatGPT 계정으로 처음 접속하면 관리자 결속이 자동 생성된다. 최초 결속 전에는 대표 이메일을 소유한 현재 ChatGPT 계정을 신뢰하는 1회 초기화 경계가 남는다.

결속 후 대표의 ChatGPT 안정 사용자 ID가 실제로 변경되면 새 ID를 자동 승인하지 않는다. 계정 소유권을 별도로 확인하고 운영 D1을 백업·감사한 뒤 `owner / primary` 결속 행만 통제된 절차로 제거해야 새 ID를 다시 결속할 수 있다. 이 복구는 관리자 탈취 위험이 있으므로 자동화하지 않는다.

이번 개발에서는 실제 운영 D1/R2 행을 읽거나 변경하지 않았다. 공개 범위, D1 `DB`, R2 `AI_SOURCE_FILES`, 고객 자료 보관 정책도 바꾸지 않았다.

## 검증

- 수정 전: 다른 안정 사용자 ID + 대표 이메일로 관리자 상태 조회 HTTP 200 재현
- 수정 후: 같은 요청 HTTP 403, 기존 결속 ID + 변경 이메일 HTTP 200
- 관리자/회원 중복 결속 차단, 최초 결속 동시 요청 2건 중 1건만 성공
- 결속 저장 장애 시 HTTP 500과 관리자 행 미생성
- 대표 이메일의 가입·직접등록·기존 파트너 이메일 편집 차단과 상태 무변경
- 버전 115 회원 결속의 추가형 마이그레이션 보존
- Node 회귀검사 485개 통과
- 격리 workerd + D1/R2 검사 178개 통과
- 타입검사, 전체 lint, 프로덕션 빌드 통과
- 로컬 운영 Worker `/`, `/account`, `/account/setup` HTTP 200
- 격리 검증의 운영 쓰기·메일·유료 AI·외부 요청 0건

기능 커밋은 `6f7b3e236c218aa911c9a007537f5446086091a5`와 후속 편집 경계 `2b0399ef6da9acae2e0a38bcf84ffe9aea451107`이다. 최종 Sites 저장본은 버전 117 (`appgprj_6a92514801988191b79eb9bd314e3fcd~appgver_cb6fe44a777881918972783f0979471f`)이며 공개 운영 배포 전이다. 중간 저장본 버전 116은 후속 보완으로 대체해 배포하지 않는다.

# 상담 FLOW 선택 입력 안전성

2026-09-03 기준. 상담 FLOW에서 업무 결과와 후속 처리에 영향을 주는 선택값·담당자가 자동 확정되지 않도록 보완한 기록이다.

## 확인한 문제

- 진행솔루션 확정의 추가서류 필요 여부가 신규 결정에서도 `필요함`으로 자동 선택됐다.
- 수령서류의 대표 검토 결과가 `검토 완료`로 자동 선택됐다.
- 새 서류요청의 전달 경로와 필수 여부가 각각 `카카오톡`과 `필수`로 자동 선택됐다.
- 신규 사후관리의 관리 담당자가 실제 배정 확인 없이 `김성민 대표`로 고정 입력됐다.
- 빈 예/아니오 선택을 단순 비교하면 `false`로 바뀌어 명시적인 `아니오`와 구분되지 않을 수 있었다.

## 적용한 동작

- 추가서류 필요 여부, 대표 검토 결과, 전달 경로, 필수 여부는 선택 안내만 보이는 빈 상태로 시작한다.
- 공통 선택 UI에 `required`를 적용해 사용자가 실제 항목을 골라야 제출한다.
- 예/아니오 변환은 `yes`와 `no`만 불리언으로 바꾸고 빈 값·임의 값은 `undefined`로 남겨 기존 서버 검증이 거절하도록 한다.
- 기존 진행솔루션을 다시 편집하면 저장된 추가서류 필요 여부를 그대로 표시한다.
- 신규 사후관리의 수행 내용·점검일·관리 담당자는 빈 상태로 시작한다.
- 기존 사후관리를 업데이트할 때는 저장된 수행 내용·점검일·담당자를 다시 표시한다.

## 운영 경계

- 상담 종류·참석 방식은 별도 후속 점검 대상으로 남겨 이번 변경에 포함하지 않았다.
- 기존 결정·검토·서류요청·사후관리 기록을 변경하거나 재분류하지 않는다.
- 추가서류·검토·전달·필수 여부의 의미와 서버 단계·권한 검증, DB/R2 스키마, 보관 정책은 변경하지 않았다.
- 실제 상담 FLOW 저장, 서류 발송, 운영 데이터 쓰기, 메일, 유료 AI, 외부 요청은 검증 중 모두 0건이다.

# 상담 FLOW 1차 보고서 작업 생성 효과 무결성

기준일: 2026-09-06

## 보완 내용

`queue_report1` 명령의 상태 변경을 명령에 결속된 새 1차 AI 작업 한 건에 정확히 제한했다.

- 새 작업 ID를 `{명령 ID}-job`, 단계를 1, 생성시각을 FLOW 갱신시각으로 고정한다.
- AI 자동생성이 승인된 상태에서는 새 작업을 빈 사유의 `queued`로 만든다.
- AI 자동생성이 중지된 상태에서는 새 작업을 `blocked`로 만들고 대표 승인 필요 고정 사유를 사용한다.
- 기존 작업의 값과 순서를 모두 보존하고, 여분 작업 추가·작업 삭제·재정렬을 거절한다.
- 애플리케이션 커밋 검사와 추가형 `0075` D1 트리거가 같은 효과를 독립 강제한다.
